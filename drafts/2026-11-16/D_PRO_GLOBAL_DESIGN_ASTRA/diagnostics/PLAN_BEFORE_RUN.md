# DIAGNOSTIC_ONLY — 事前固定計画

2026-11-16。数値評価前に作成。証明・反例証明・較正ではない。

二値の問いは次の二つだけ。
1. 固定標本すべてで、二つの固定求積設定の双方が V > 0 を返すか。
2. 同じ固定標本すべてで、双方が E_zz > 0 を返すか。

全域の符号そのものを有限標本で決定する問いではない。false は非正値・非有限・計算失敗のいずれをも含み、真の反例とは解釈しない。

参照楕円体 p=(R a,0,lambda R b), a=(1-tau²)/(1+tau²), b=2tau/(1+tau²)。標本は以下の直積。中心の重複はそのまま評価する。
- lambda: 2,206539/100000,5/2,3,4,118/25,472438/100000,472439/100000,19/4,5。
- R: 0,1/8,1/2,15/16,63/64,255/256,59999/60000,1。
- tau: 0,1/16,1/4,1/2,3/4,15/16,1。
- 追加の固定標本: lambda=118/25, tau=0, R=1/64,15/512,11/256。既存の1スライスの根区間を参照するだけで、根の数値探索はしない。

接触点中心座標 u=tan(psi/4) を使う。u端点は 0 と 2^-12,2^-11,...,1。各u帯をGauss–Legendre 8点、thetaを[0,2pi]の中点64点で積分する設定と、各u帯16点・theta128点の設定を、ともに固定して全標本へ使う。倍精度NumPy。設定の差や誤差・値は保存しない。

z=0では V=E_zz、z>0では V=E_z/z。E_z,E_zzは正確な核を解析微分した式を浮動小数で評価する。D=0となる積分端点は求積点に含めない。gammaの浮動丸めを[0,1]へ制限し、gamma=1付近のR,R'は固定8項の(1-gamma²)級数、それ以外は直接式。これは診断専用で、認証用の丸め・剰余保証ではない。

出力は DIAGNOSTIC_ONLY のファイル名の下のJSONで、Q1/Q2に対応するbool二個だけ。値、余裕、最悪点、符号変化位置、反復回数、時間は一切出力しない。例外の詳細や部分値も保存しない。判定終了まで早期打切りしない。

使用制限: Q2=trueならE_zz単独案を検討可、Q1=trueかつQ2=falseならV商案を優先可。それ以外は混合成分排除案を残す。いずれも証明ではない。標本、求積設定、出力以外の観測から認証の閾値・分割・精度・余裕・予算を選ばない。診断スクリプトを認証へ転用しない。

設計の数値例は診断から独立に固定する: 中心R=1/8、一般域上端15/16、zの商切替例1/8、外箱初期8×16×24、内側初期32×32、producer160/checker192 bits。薄層幅は未取得の厳密境界下界と解析的連続率から構成する。時間は仮定した単価によるシナリオ表とし、この診断は計時しない。
