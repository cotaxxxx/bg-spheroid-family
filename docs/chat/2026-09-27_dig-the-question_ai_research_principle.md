# AI時代の研究は、答えを掘るんじゃなく、問いを掘る。

Date: 2026-09-27

> この記録はAI共同研究の軌跡を保存する研究史ログであり、RAW evidence・D-OB producer/checker evidence・正式な数学的証明ではない。

## Key phrase

> **AI時代の研究は、答えを掘るんじゃなく、問いを掘る。**

## Conversation trail

研究を進める中で、単に既存の問いへの答えを深く探索しているのではなく、得られた結果によって問題提起そのものが変動していることを確認した。

概念的には、

```
Q0 → A0 → Q1 → A1 → Q2 → ...
```

であり、答え A が終点ではなく、次の問い Q を生成する。

問いは一本道とも限らない。

```
          ┌→ 数値の問い
Q0 → A0 ─┼→ 幾何の問い
          └→ 対称性の問い
```

別々に掘られた問いが、後に再び同じ数学的構造へ接続することもある。

## Global certification

大域認証は、この「問いを掘る」研究方法が特に明瞭に現れた工程である。

最初は、

> この性質は大域的に成立するか？

という問いでも、認証を実行しようとすると、

- 「大域的」とは何を覆えば十分なのか
- 端点・退化極限をどう扱うのか
- 数値観測と証明可能な主張の境界はどこか
- producer/checker をどのように独立させるのか
- 何を evidence と認めるのか
- そもそも「認証」とは何を意味するのか

へと問い自体が深くなる。

したがって、

```
対象について問う
→ 成立条件を問う
→ 例外を問う
→ 認証可能性を問う
→ 「認証」の定義を問う
```

という研究過程になる。

## AI era

AI・計算機・形式証明系によって、適切に定式化された問題については、証明候補探索、反例探索、補題分解、計算検証、形式検証に投入できる能力が大きくなっている。

その結果、研究上の希少性は相対的に上流へ移る。

```
何を問うか
→ 何を定義するか
→ 何を不変量と見るか
→ 何を証明すれば本質を捉えたことになるか
```

「問いを立てる」だけではなく「問いを掘る」と表現する理由は、最初の問いを固定せず、その前提・限界・隠れた構造を調べ、必要なら問いそのものを作り直すからである。

## Human–AI research trail

AI共同研究のログで保存すべきなのは、最終回答だけではない。

```
問いの誕生
→ 検証
→ 失敗・例外
→ 問いの修正
→ 新しい構造
→ 新しい問い
```

この履歴を保存することで、後から研究全体の **Question Tree（問いの樹）** を再構成できる。

完成した論文やコードだけでは失われやすい「なぜ次の問いへ進んだのか」を残すことが、AI共同研究の研究史として重要になる。

## Research principle

> **AI時代の研究は、答えを掘るんじゃなく、問いを掘る。**

答えが出るたびに、それを終点にせず、その答えによって初めて見える次の問いを掘る。
