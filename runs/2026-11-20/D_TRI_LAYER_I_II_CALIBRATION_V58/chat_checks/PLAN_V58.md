## 較正の設計（Codex の CAL_PLAN と同じ形と位置）
- 形：s を 11/20 刻み、t を 5/8 刻みに分けた 4 × 8 ＝ 32 枚のタイル。
- 位置のパッチ（能動な座標の半幅 1/1024。第一八分体と閉球に制限）：
  W₃ ＝ E₃/q₃ を oct (1/4, 1/4, 1/2)、face13 (1/4, 0, 1/2)、face23 (0, 1/4, 1/2)、rim13 (3/5, 0, 4/5) で。
  H₃₃ を plane (1/4, 1/4, q₃ ∈ [0, 1/1024]) で。
  C₁₂ ＝ T₁₂/(q₁q₂) を disk (1/2, 1/2, 0)、rim12 (3/5, 4/5, 0)、disk2 (1/4, 1/2, 0) で。
- 段階 A：タイル全体。N ＝ 64 で一回。
- 段階 B：タイルの中心の、幅 1/64 の入れ子の形の箱。N ＝ 64 で決まらなければ 128、256。
- 段階 C：タイル全体を、位置のパッチを固定して適応的に分割する。V57 と同じ規則（形の項の幅が角度の項より大きく深さ < 10 なら 4 分割、そうでなければ N を倍、上限 256）。1 組あたり 300 秒。対象はタイル (0,0)、(1,3)、(2,5)、(3,7) の 4 枚 × 8 パッチ。
- 段階 D：段階 B の入れ子の形の箱で、位置の箱の幅を 2⁻³、2⁻⁴、…、2⁻⁹ と変える。N ≤ 256 で符号が出る最大の幅を記録する。中心はパッチの中心（rim は閉球の内側へ寄せた箱）。
- 記録：結果、評価の回数、CPU 秒、葉の数、深さ。符号の出なかった行も全部残す。
- 外挿：段階 C と D の実測から、層 I・II の被覆に要る箱の数と時間を見積もる。見積もりの式は報告書に明記する。
