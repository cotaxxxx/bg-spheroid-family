# Codex への研究指示書｜扁平族の円板極限：縁の層を閉じる（λ < 1/32）

2026-11-20 ／ 発注：Judge（ユーザー、ボタンで回答）／ 起草：chat ／ 扱い：DIAGNOSTIC_ONLY / NOT_EVIDENCE

**単発の依頼である。** 方法、道具、分量は自由である。守ってほしいのは §5 だけである。

## 1. 目的

λ ∈ (0, 1/32) で、軸の外の内部（ρ > 0）と、境界赤道以外の境界に、停留点がないことを示す。境界の零集合は、内側から延長した全勾配のトレースで定める。これが閉じれば、体積を保つ回転楕円体の族の停留点の構造が、λ ∈ (0, ∞) の全体で決まる。

## 2. 採用済みのこと（あなたの前回の報告 D_OB_FULL_FAMILY と、chat の監査 V53、Judge が採用）

- **λ ∈ [1/32, 1]：** 内部と境界の全体の分類
- **λ ∈ (0, 1/32)：**
  - 中心：H(0, 0) > 0（§3 の正の表示）
  - 軸：E_zz(0, z) ≤ −λ/2（§2）
  - 両極：E_z ≠ 0
  - 境界赤道：H_b ≥ λ/6（§7）
- **境界赤道の近傍：** √((1 − ρ)² ＋ z²) ≤ λ⁴/384 ならば E_ρ ≥ λ/12（§7。‖∇²E‖ ≤ 9π/λ³ を使う）
- **漸近：** 固定した η > 0 について、ρ ≤ 1 − η で H ＝ πλ log(1/λ) h(ρ) ＋ O_η(λ)。h > 0（§4）。
  - ただし剰余 O_η(λ) は明示されていない。η → 0 での一様性もない。

## 3. 残る問題

固定した尺度（ρ ≤ 1 − η）と、λ⁴ の近傍の間を、一様につなぐこと。報告書 §6 の言葉では、**1 − ρ、|z|、λ が同時に小さい層での、E_ρ の明示的な下界**である。境界の赤道以外の点（0 < z < 1、ρ ＝ √(1 − z²)）も含めること。

その点では、E_ρ > 0 か E_z ≠ 0 のどちらかを示せば足りる。

## 4. 考えてほしいこと（制限なし）

1. **剰余の明示：** §4 の漸近補題の剰余 O_η(λ) を明示すること。η と λ の関数として書き、η ＝ η(λ) を λ とともに小さくできる範囲を出すこと。
2. **縁の尺度：** 縁での拡大変数を使うこと。例えば X ＝ (1 − ρ)/λᵃ、Z ＝ z/λᵇ である。内部の層と外部の層を接続し、H か E_ρ の符号を一様に出すこと。
   - H_b/λ → 2 と、§7 の方位平均の恒等式が手がかりになる。
3. **λ₀ の明示：** 解析で閉じる範囲を (0, λ₀] とし、λ₀ を明示すること。λ₀ < 1/32 なら、[λ₀, 1/32] は区間計算で覆う。あなたの thin、mixed、rim の手法がそのまま使える。
4. **監査への配慮：** chat は GeoEncloseReader 0.2.1（λ < 1、段差のある m の格子）で抜き取りの監査をする。λ < 1/16 の縁の近くは、Reader でも 1 葉の評価に数分かかる。補題の形で閉じる部分を多くしてほしい。
