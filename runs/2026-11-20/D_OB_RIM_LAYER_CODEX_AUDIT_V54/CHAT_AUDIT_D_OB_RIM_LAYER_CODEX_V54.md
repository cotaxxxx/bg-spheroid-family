## 0. 結論

**証明は正しいと判断する。** これで縁の層が閉じた。

0 < λ ≤ 1/32 で、次の二つが成り立つ。

```text
E_z(ρ, z)/z ≤ −(6/55)λ   （z ≠ 0）
E_ρ(ρ, 0) ≥ λρ/24        （0 < ρ ≤ 1。赤道面の不等式は 0 < λ < 1 の全体で成り立つ）
```

- z ≠ 0 の点は、内部でも境界でも E_z ≠ 0 である。
- 赤道面の ρ > 0 の点では E_ρ > 0 である。
- したがって、停留点は中心だけになる。境界の零集合は空である。
- λ → 0、ρ → 1、z → 0 がどの速さで近づいても成り立つ。

**これで、体積を保つ回転楕円体の族の停留点の構造が、λ ∈ (0, ∞) の全体で決まる。**

この結果は、前回の付録の漸近補題を使わない。二つの短い解析の補題で閉じている。有限の区間被覆もない。

- 赤道面での鏡映の補題
- 軸方向の凹性の補題
