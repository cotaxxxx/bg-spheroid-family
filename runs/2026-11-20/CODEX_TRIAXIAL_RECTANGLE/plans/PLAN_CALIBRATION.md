# 主矩形の軸外排除の較正 計画 C1

2026-11-20 / DIAGNOSTIC_ONLY / NOT_EVIDENCE

## 目的と対象

全域の被覆を始める前に、有限幅の形状箱・位置箱における G3 と面12の角差商 D12 の区間幅と実行時間を測る。
形状は L=diag(1,s,st), A=L^T L。主矩形は 1<=s<=16/5, 1<=t<=6。
以下の32形状箱は較正用であり、矩形の被覆ではない。

- s 中心：65/64, 5/4, 2, 51/16。
- t 中心：65/64, 3/2, 2, 9/4, 3, 4, 5, 383/64。
- 各形状座標の半幅：2^-12。
- shape ID は s の順を外側、t の順を内側とする0始まり。
- 全ての箱端点を 2^-16 の整数単位で台帳に記録する。

各形状につき次の4位置箱を用いる。非零座標の半幅は2^-13、0の座標は厳密に0。

| モード | 位置中心 | 量 |
|---|---|---|
| G3_123 | (1/4,3/8,1/2) | E3/q3 |
| G3_13 | (3/8,0,1/2) | E3/q3 |
| G3_23 | (0,3/8,1/2) | E3/q3 |
| D12 | (1/2,1/2,0) | (G2-G1)/(A2-A1) |

## 数式と保証

G3 は最初の地図の式(1)を直接区間評価する。
D12 は式(4)から得る

    D12=< k gamma P [v1 v2 / D^2 - xi1 xi2/(A1 A2 B)] >/(q1 q2)

を用いる。この式では A2-A1 を除算しない。今回は q1,q2 が0から離れた箱だけを扱う。
球面座標は mu=xi3 in[-1,1], w=tan(phi/2) in[0,1] とし、4象限の符号を明示的に加える。
xi1=+-sqrt(1-mu^2)(1-w^2)/(1+w^2), xi2=+-sqrt(1-mu^2)2w/(1+w^2)。
確率測度は (dmu/2)4dw/[pi(1+w^2)]、4象限の平均を取る。

binary64の基本演算と平方根を各段でnextafterにより外側へ広げる。πはMachin公式と24項の有理交代級数で包む。
角度関数は原本と同じ arcsin の正項級数（54次、尾部<=2^-54）を用いる。
gamma刻み2^-16の表を作り、単調な R=gamma P,J=gamma P-F,K=gamma^2 P の両外端を採用する。
数値積分はセル全域の範囲に正の測度を掛けた和で、各加算も外向き。点求積は包囲に用いない。
IEEE754の通常の最近接丸め、正しく丸める基本演算・平方根、段階的アンダーフローを仮定する。

## 実行規則

- nmu=64,128,256,512,1024、nw=nmu/2の順に試す。
- その箱で下端>0になったら終了する。
- 上限でも0を含む場合はunresolvedとして保存する。条件を変える場合は別計画を固定する。
- 最初にshape 0の4モードで動作と所要時間を確認し、その後shape 1〜31を実行してよい。
- CPU並列は最大2プロセス。研究PCは使用しない。
- 実行前に本計画とcode/calibration.pyのSHA-256を保存する。
- 全段の出力を保存し、終段だけを残すことはしない。時間は再実行で変わるので再現比較では数値端点と判定を別に照合する。

## 未処理の範囲

境界、中心、軸に近い q1*q2=0、q3=0 のカラー、s=1およびt=1の対称辺、32形状箱の隙間はこの較正の被覆外である。
成功箱の幅・速度を外挿しても、全域の証明費用の上界にはならない。
