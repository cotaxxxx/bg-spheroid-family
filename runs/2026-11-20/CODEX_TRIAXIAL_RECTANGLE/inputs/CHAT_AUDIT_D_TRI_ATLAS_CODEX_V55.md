## 3. 手による照合

- **§4.2：** 次を確かめた。
  - (5) は、k が L によらないことと、∂_ε log γ ＝ Σβ_i(n_i² − u_i²) から出る。
  - テンソル ⟨kPγ(uuᵀ − nnᵀ)⟩ のトレースは零である。β ＝ (0, 1, 1) なので ∂_εE ＝ −T₁₁ となり、円の上では c₀ ＋ c cos 2φ の形になる。

## 5. Judge に判断してもらう点

1. **局所定理（t ＝ 3 の近く）、球の近傍、扁平の辺からの続きを、研究成果として採用するか。** chat の推奨は「採用する」である。どれも近傍の存在定理で、近傍の大きさは数値では出ていない。
2. **次の一手（Codex の選択肢 B と C）：**
   - **chat の推奨は B（有限の矩形の地図を定理にする）である。** 興味のある構造はすべて主矩形 [1, 3.2] × [1, 6] の中にある。四つの臨界曲線、軸の上の枝、交差点がそこに収まる。
   - 最初に Codex の工程 3（軸の上の根の数を U_i の単調性で決める）と、工程 2 の較正（G₃ > 0 と、面 12 の角差商を 32 個の形の箱で測る）を行うとよい。そうすれば、一番危険な「軸の外の排除」の費用が実測で分かる。
   - 無限遠（C）は、その後に回してよい。§5.4 の順序の逆転は、すでに見えている。
