# Codex への研究指示書｜三軸の族：主矩形 [1, 3.2] × [1, 6] の分類を定理にする

**単発の依頼である。** 方法、道具、分量は自由である。守ってほしいのは §6 だけである。

## 1. 目的

あなたの最初の地図（`5fbd120e`、chat 監査 V55）の主矩形 R ＝ {1 ≤ s ≤ 3.2, 1 ≤ t ≤ 6} で、停留点の構造を定理にすること。

- 内部の停留点と、境界の全勾配のトレースの零を分類する。
- Morse 指数を付ける。
- R の辺 s ＝ 1 と t ＝ 1 は、回転楕円体の採用済みの答えを使う。

## 2. 採用済みのこと

- 回転楕円体の族の全体（`6b1bc9e`）
- 三軸の局所定理（V55）
  - t ＝ 3 の近傍の 5 点
  - 球の近傍
  - 扁平の辺からの続き
- あなたの式 (1)〜(6) を、chat が独立に照合した。
  - 勾配のトレース
  - 弦の Hessian
  - 中心の三積分
  - 角微分の因数分解 (4)
  - 円を分ける係数 (6)
- C₁、C₂ の表は、chat の求積と 6 桁一致した。

## 3. 証明してほしい形（地図からの予想。違っていたら、それを示すこと）

| 量 | 内容 |
|---|---|
| 中心 | 符号の並び (h₁, h₂, h₃)。h₃ > 0 は R の全体で成り立つ。h₁、h₂ は、それぞれ C₁、C₂ の上でだけ零になる |
| 短軸 e₁ | b₁ < 0 < h₁ のとき、ちょうど一つの対がある（指数 1）。それ以外では対はない |
| 中間軸 e₂ | b₂ < 0 < h₂ のとき、ちょうど一つの対がある（指数 2）。それ以外では対はない |
| 長軸 e₃ | 対はない（R で U₃ > 0） |
| 軸の外 | 内部にも境界にも、停留点も全勾配の零もない |
| 境界の零 | B₁、B₂ の上の、対応する軸の端点だけ |

C₁、C₂、B₁、B₂ は、R の中の滑らかな曲線（例えば t ＝ f(s) のグラフ）である。端点は辺の臨界値で、どれも辺に横断的に交わる。

## 4. 進め方の提案（あなたの §6 に沿う。順序と方法は自由）

1. **軸の根の数：**
   - U_i(x) ＝ g_i(√x)/√x として、R の各形で、零があれば単純な下向きの横断であること（∂_xU_i < 0）を示すこと。中心の側は偶 Taylor 係数、外端の側は全トレースと片側勾配で扱う。
   - 根の上で、横の固有値の符号も同時に包むこと。これが軸から開面への二次分岐の検査になる。
   - 長軸では U₃ > 0 を示すこと。
2. **四つの臨界曲線：**
   - h_i、b_i の符号を形の箱で包み、符号が決まらない細い帯だけをパラメータ付き区間 Newton に渡すこと。
   - 交差点 C₁ ∩ B₂（約 (1.567, 2.297)）は、二変数の系として分離すること。
3. **軸の外の排除（一番の危険）：**
   - **まず較正すること。** 32 個の形の箱で、次を区間で測ること。
     - 開八分体と面 13、23 での G₃ > 0
     - 面 12 での (G₂ − G₁)/(A₂ − A₁) の下界、または同時零の排除
   - **実測した余裕と箱の幅から、R の全体の予算を出すこと。** 予算が現実的なら、R の全体へ広げること。
   - 扁長の辺の近くでは、(6) の分裂の正規形を、t の円の存在帯 (λ_b^pro, λ_c^pro) で一様に使うこと。帯の両端では正規化が必要である（r → 0 では c/r²、r → 1 では境界の標準形）。
4. **境界：**
   - 軸の外の境界点では、全勾配のトレースが零でないことを示すこと。
   - 軸の端点の零は、B_i の上だけであることを示すこと。
5. **組み立て：** R の全体で、分類と Morse 指数の表を作ること。予想と違う構造が見つかれば、それを優先して報告すること。
