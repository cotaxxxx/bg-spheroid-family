# chat の偵察：三軸の族の中心の Hessian（DIAGNOSTIC_ONLY / NOT_EVIDENCE、非区間）

## 方法

弦の表示 (3) を q ＝ 0 に特殊化した。v ＝ 0、d ＝ 1、両側とも ℓ ＝ 1 となるので、

```text
E_ii(0) ＝ ⟨T[P(T)L_ii²/C(1 − L_ii²e_i²/C) − Q(T)e_i²(1 − L_ii²/C)²]⟩_e
T ＝ (CB)^(−1/2)
```

である。L ＝ diag(1, s, st) とした。求積は Gauss–Legendre の 96 × 192 点である。

## 照合

| 場合 | 値 | 期待値 |
|---|---|---|
| 球 | 4/3 | 4/3 |
| 扁平 λ ＝ 0.5（s ＝ 2、t ＝ 1） | 軸 0.2369730、横 1.5887418 | D-OB の 0.236973、V53 の 1.58874181 |
| 扁長 λ ＝ 4.724383（s ＝ 1） | 横の二重の固有値 3.8×10⁻⁸ | 0（λ_c^pro） |

## 所見（数値の地図であり、証明ではない）

**h₁（最短軸）の零曲線：** 扁長の辺の λ_c^pro（s ＝ 1、t ＝ 4.724）から出て、扁平の辺の λ_c^ob で終わる。終点は t ＝ 1、s ＝ 2.4512275558 で、1/λ_c^ob ＝ 2.4512275576 と一致する。

**つまり、回転楕円体の族の二つの「中心の分岐」は、三軸の三角形の中で一本の曲線の両端になっている。**

| 曲線 | 振る舞い |
|---|---|
| h₂（中間軸）の零曲線 | λ_c^pro から出て、t ≈ 5〜6 のまま s → ∞ へ伸びる |
| h₃（最長軸）の零曲線 | 細長い領域（例えば (3, 12) から (10, 4)）に現れる。h₂ の曲線と (7.5, 5.8) 付近で交わる。二つの固有値が同時に零になる余次元 2 の点である |
