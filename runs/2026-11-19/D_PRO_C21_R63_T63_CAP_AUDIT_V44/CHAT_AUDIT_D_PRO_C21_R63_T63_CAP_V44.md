### 座標の対応（手で確かめた）

板の座標は ρ ＝ R(1 − τ²)/(1 + τ²)、z ＝ R·2τ/(1 + τ²) で、R, τ ∈ [63/64, 1] である。

- 2τ/(1 + τ²) は τ ≤ 1 で増加する。よって z の最小は R ＝ τ ＝ 63/64 のときで、z ≥ 7938/8065 > 0 である。
- (1 − τ²)² ＋ (2τ)² ＝ (1 + τ²)² より、ρ² ＋ z² ＝ R² ≤ 1 である。
- χ ＝ 1 − z² ≤ 1 − (7938/8065)² ＝ 2032381/65044225 である。λ ≤ 5 なら λ²χ ≤ 2032381/2601769 < 1 になる。
- したがって、(G7) の w ＝ λ√χ ≤ 1、u ＝ ρ/√χ ≤ 1 に入る。u ≤ 1 は ρ² ≤ χ ⟺ R ≤ 1 と同じである。
- 箱は回転軸の線分（τ ＝ 1、ρ ＝ 0）も含む。ここでも E_z > 0 なので、軸の上の停留点も排除される。
