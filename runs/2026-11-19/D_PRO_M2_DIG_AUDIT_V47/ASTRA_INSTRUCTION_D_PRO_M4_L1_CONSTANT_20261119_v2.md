## 2. 固定する定義

```text
ε ＝ 1/λ
S ＝ √(1 − z²)
S₀ ＝ 2⁻¹²
δ ＝ 1 − ρ² − z²（接触境界までの距離）
対象領域：λ ≥ Λ₁ ≥ 5、S ≥ S₀、0 < ρ < S
```

M1 の厳密な恒等式：

```text
H/ε ＝ −(πS/2)A_λ ＋ (3S²/2)B_λ ＋ R_H^(2)
A_λ ＝ asinh(λ(1 − z)) ＋ asinh(λ(1 + z))
B_λ ＝ arctan(λ(1 − z)) ＋ arctan(λ(1 + z))
```

これらの初等関数は、粗い対数の下界に置き換えず、正確な形のまま使うこと（V47）。

### 2.1 実測値（chat、非区間。目安であり証明ではない）

| λ | min_z T_λ(z) | 最小の位置 |
|---|---|---|
| 5 | 3.145 | z ＝ 0 |
| 10 | 5.006 | z ＝ 0 |
| 32 | 7.565 | z ≈ 0.999（極の側） |
| 100 | 9.394 | z ≈ 0.9999（極の側） |

ここで T_λ(z) ＝ (π/2)A_λ − (3S/2)B_λ である。λ ＝ 5 での R_H^(2)/S は次のとおりである。

| 点 | R_H^(2)/S |
|---|---|
| 中心 | 3.023 |
| q ＝ (0.3, 0.4) | 2.876 |

**したがって、Λ₁ ＝ 5 を狙うなら C < 3.145 が必要で、余裕は約 4 % しかない。** Λ₁ ＝ 10 なら C < 5.0 で足りる。C を少し緩く取り、Λ₁ を少し大きくする方が現実的である。

## 3. 主課題 L1

### L1-A：残差の一様上界

有限の明示的な定数 C と Λ₁ ≥ 5 を与え、次を示すこと。

```text
λ ≥ Λ₁、S ≥ S₀、0 < ρ < S のすべてで  R_H^(2)(λ, ρ, z)/S ≤ C
```

特に、δ → 0⁺ でも定数が発散しないことを示すこと。

### L1-B：初等関数の閾値

C が得られたら、次を満たす有限の Λ₁ を導くこと。

```text
λ ≥ Λ₁ のすべてで  min_{|z| ≤ √(1 − S₀²)} [(π/2)A_λ(z) − (3S/2)B_λ(z)] > C
```

λ ＝ Λ₁ の一点だけでなく、λ ≥ Λ₁ のすべてで示すこと。例えば、λ について単調に増えることを示す。

- A_λ も B_λ も λ について増加するので、T_λ の単調性は自明ではない。
- chat の非区間の実測では、λ ＝ 5〜100 で ∂T/∂λ > 0（最小 0.016）だった。これは証明ではない。

**L1-A と L1-B が両方成り立つ場合に限り、非極の H < 0 が従う。**

## 4. 数学的な実施順序

### 4.1 残差核を元の定義から組み立て直す

R_H^(2) を、二つの漸近の尾を被積分関数の段階で引いた積分として明示すること。次を必ず示すこと。

1. 元の H の積分核
2. 第一の尾の核と、その積分値
3. 第二の尾の核と、その積分値
4. 引き算後の残差の核
5. 各変形が成り立つ変数の範囲と、端点での扱い

形式的な漸近展開ではなく、有限の ε > 0 での厳密な恒等式を優先すること。

### 4.2 三つの領域での評価

残差の核を、次の三つに分けて評価すること。

- 近い領域：|t| ≤ 1
- 遠い領域：|t| > 1
- 接触カラー：δ → 0⁺

V46 では、固定した内部の点で O(|t|⁻³) の減衰が確かめられている。ただし、この次数だけでは足りない。

|K_rem| ≤ M/(1 ＋ |t|)³ のような評価を使う場合は、係数 M が ρ、z、δ、λ について一様であることを証明すること。一様でない場合は、発散する因子を明示すること。

**接触カラーの手がかり（chat）：**

- **小さな帽子の中では、絶対値の評価でも δ に一様な定数が出る。** V45 の (NP8) は、密度の Hessian の絶対値を、どの点でも 2π√B/D で押さえる。t の変数では 1/√(t² ＋ A) の形で、接触の近くでは A₀ ≈ δ² ＋ cφ² である。帽子の中の積分は t について log、φ についてその平均になり、δ → 0 でも有限である（(NP9) と同じ計算）。
- **代償がある。** 全体の絶対値の上界は約 2πT_λ で、余裕より大きい。帽子の半径 r を余裕に収まる程度に小さく取り、帽子の外では引き算後の核の展開を使う。帽子の中と外の定数が、r の関数として釣り合うかを確かめること。

### 4.3 相殺を保つこと

残差の核を項に分けて絶対値で評価すると、必要な相殺を失う可能性がある。その場合は、相殺を保った評価を試みること。例えば、共通の分母、反射の対、角度の平均、正の分母による表示などがある。

ただし、Δ_H ＝ T_λ − R_H^(2)/S ＝ −λH/S は既知の恒等式である。これを書き換えただけでは、新しい評価にはならない。**新しい上界、不等式、または積分の評価の改善を明示すること。**

## 5. 代替の経路：(G1) で極の側を排除する

L1 の直接法と並行して、次の分け方を検討すること。

```text
λS ≤ K  ⟹  E_z > 0
λS ≥ K  ⟹  H < 0
```

既存の (G1) は、λS ≤ 1 の層（w ≤ 1）を扱える。これを K > 1 へ広げられるかを検討すること。

注意が二つある。

- (G9) の北の項 εw²√(1 ＋ w²)/(1 ＋ z) は、w が大きいと膨らむ。既存の評価をそのまま延長してはならない。
- (G1) の区間下界は、w ≤ 1 でも λ ≥ 80/19 ≈ 4.21 までしか正にならなかった（V43 の診断）。

直接法と (G1) 併用法を比べ、次を報告すること。

- どちらが小さい Λ₁ を期待できるか
- どちらが接触カラーを簡単に扱えるか
- 新たに必要になる補題は何か

(G1) の拡張は、証明されるまで仮定として扱うこと。
