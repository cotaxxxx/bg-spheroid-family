## 2. 固定する定義

\[
\varepsilon=\frac1\lambda,\qquad
S=\sqrt{1-z^2},\qquad
S_0=2^{-12}.
\]

対象領域：

\[
\lambda\geq\Lambda_1\geq5,\quad
S\geq S_0,\quad 0<\rho<S.
\]

接触境界への距離を

\[
\delta=1-\rho^2-z^2
\]

とする。

M1 の厳密恒等式：

\[
\frac H\varepsilon
=-\frac{\pi S}{2}A_\lambda
+\frac{3S^2}{2}B_\lambda
+R_H^{(2)},
\]

ただし

\[
A_\lambda=
\operatorname{asinh}(\lambda(1-z))
+\operatorname{asinh}(\lambda(1+z)),
\]

\[
B_\lambda=
\arctan(\lambda(1-z))
+\arctan(\lambda(1+z)).
\]

これらの初等関数は、粗い対数下界に置き換えず、正確な形を保持すること。

## 3. 主課題 L1

次の命題を証明する。

**L1-A：残差の一様上界**

有限の明示定数 \(C\) と \(\Lambda_1\geq5\) を与え、

\[
\boxed{
\frac{R_H^{(2)}(\lambda,\rho,z)}S\leq C
}
\]

が、すべての

\[
\lambda\geq\Lambda_1,\qquad
S\geq S_0,\qquad
0<\rho<S
\]

で成り立つことを示す。

特に \(\delta\to0^+\) でも定数が発散しないことを証明する。

**L1-B：初等関数の閾値**

L1-A の \(C\) が得られたら、

\[
\boxed{
\min_{\substack{|z|\leq\sqrt{1-S_0^2}}}
\left[
\frac{\pi}{2}A_\lambda(z)
-\frac{3S}{2}B_\lambda(z)
\right]>C
}
\]

を満たす有限の \(\Lambda_1\) を導出する。

L1-A と L1-B が両方成立した場合に限り、非極の \(H<0\) が従う。

## 4. 数学的な実施順序

### 4.1 残差核を原定義から再構成

M1 の \(R_H^{(2)}\) を、二つの漸近尾を被積分関数の段階で引いた積分として明示する。

以下を必ず示す。

1. 元の \(H\) の積分核。
2. 第一尾の核と積分値。
3. 第二尾の核と積分値。
4. 引き算後の残差核。
5. 各変形が成り立つ変数範囲と端点での扱い。

形式的な漸近展開だけでなく、有限 \(\varepsilon>0\) における厳密な恒等式を優先すること。

### 4.2 三領域の評価

残差核を次の領域に分けて評価する。

- 近接領域：\(|t|\leq1\)
- 遠方領域：\(|t|>1\)
- 接触カラー：\(\delta\to0^+\)

V46 では固定内部で \(O(|t|^{-3})\) の減衰が確認されている。

ただし、この次数だけでは不十分である。

\[
|K_{\mathrm{rem}}|
\leq \frac{M}{(1+|t|)^3}
\]

のような評価を使う場合、係数 \(M\) が \(\rho,z,\delta,\lambda\) に一様であることを証明すること。

一様でない場合は、発散する因子を明示する。

### 4.3 相殺の保持

残差核を個々の項に分解して絶対値評価すると、必要な相殺を失う可能性がある。

その場合は、共通分母・反射対・角度平均・正の分母表示などを用いて、相殺を保持した評価を試みること。

ただし、

\[
\Delta_H=
T_\lambda-\frac{R_H^{(2)}}S
=-\frac{\lambda H}{S}
\]

は既知の恒等式である。

これを書き換えただけでは、新しい評価を得たことにならない。

**新しい上界、不等式、または積分評価の改善を明示すること。**

## 5. 代替経路：G1 による極側の排除

L1 の直接法と並行して、次の分割を検討する。

\[
\lambda S\leq K
\quad\Longrightarrow\quad E_z>0,
\]

\[
\lambda S\geq K
\quad\Longrightarrow\quad H<0.
\]

既存の G1 は \(\lambda S\leq1\) の層を扱える。

これを \(K>1\) へ拡張できるか検討すること。

ただし、G9 の北側項は \(w\) が大きい場合に膨らむため、既存評価をそのまま延長してはならない。

直接法と G1 併用法を比較し、次の点を報告する。

- どちらが小さい \(\Lambda_1\) を期待できるか。
- どちらが接触カラーの扱いを簡単にできるか。
- 新たに必要となる補題は何か。

G1 の拡張は証明されるまで仮定として扱うこと。
