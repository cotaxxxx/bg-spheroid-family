# 有限被覆 3　実行前の計画

2026-11-19 ｜ **DIAGNOSTIC_ONLY / NOT_EVIDENCE**

試作 2 の格子をそのまま全体に当てると中心付近の外箱に非負上端が残った。新たに次の被覆を固定した。数学的な条件は外箱全体の \(H\) 上端が厳密に負であること。試作 1、2 の記録は保持する。

1. 根は \(\lambda\in[5,6],[6,7],[7,8]\) の 3 枚、各 \((\rho,z)\in[0,1]^2\)。北半球および閉単位球、\(S\ge1/\lambda\) に制限する。円盤またはこの帯の外に厳密に入る箱だけは空としてよい。境界等号は含める。さらに試作 1 の \(\lambda=5\) の三上端を \(1,1,-3/16\) と有理数比較する。これによれば \(S\le1/\lambda,\lambda\ge5\) でも \(\sqrt{\lambda^2-1}\,H<S^2-3z^2/16\le-7/50\) であり、この領域を H で直接覆える。
2. 全外側端点は 1/4096 単位の整数。幅のスコアは \(8(r_1-r_0),8(z_1-z_0),l_1-l_0\) の順で、\(l_i\) は \(\lambda\) の整数端点。最大の値を \(h\) とし、負の上端・空が得られない場合は最大の方向を中央で二等分する。同値は表記順を優先する。
3. 積分格子 \((N_m,N_\phi)\) は \(h\ge8192:(32,4),\ h\ge4096:(64,8),\ h\ge2048:(128,16),\ h\ge1024:(256,16),\ h\ge512:(256,32),\ h\ge256:(512,32),\ h\ge128:(512,64)\)、それ以外は \((1024,64)\)。左から最初に該当するものを使う。\(h\le64\) で上端が非負なら未解決として記録する。両方位符号と弦の両端を含む。
4. 1 枚 100,000 節点または実時間 880 秒で打ち切り、残る箱は未解決と記録。3 枚並列、Codex 環境のみ。各節点の箱・格子・上端の整数分子と分母・処理を gzip 圧縮 TSV に保存する。実行の強制上限 960 秒。有限な二進分割、外向き整数演算の仕様・表は試作 2 と共通。
5. 別の検査プログラムで三枚の分割を子の端点から再構成し、抜け・重複・余分な行・空の有理条件・負の有理上端・各根の体積を確認する。また、別にコンパイルした同じセル実装で全ての終端を逆向きの順序で再演算し、有理上端が完全一致することを確認する。未解決葉が一つでもあれば、その根を全域の根拠に使わない。
6. 表の独立監査と数学的な採用は chat と Judge が行う。ここでの全葉再演算は同じセル式の再現性検査。事前 SHA を PRE3.sha256 に保存する。実装・試作の数値を判定語に置き換えない。
