# chat 監査 V52：扁平の D-OB を GeoEncloseReader で独立に照合する

2026-11-19 ／ 監査：chat ／ 道具：GeoEncloseReader 0.2.0 ／ 扱い：DIAGNOSTIC_ONLY / NOT_EVIDENCE

## 0. 結論

**D-OB の答え（λ ∈ [2/5, 33/50]、Judge V24）と食い違う結果は、一つも出なかった。** 照合したのは次の二つである。

- **横方向の H > 0（D5）：** 抜き取った 186 箱すべてで、Reader の独立な包みが H > 0 を示した。
- **軸の上の符号の構造（C-AXIS）：** 抜き取った 15 本の λ の帯で、軸の上の E_z の符号の構造が D-OB の三相と一致した。
  - 13 本は帯全体で確かめた。
  - λ_c のすぐ上の 2 本は、帯の左端の λ の一点で確かめた（§3.3）。

**範囲についての訂正：** D-OB で閉じているのは λ ∈ [2/5, 33/50] の窓だけである。扁平族の全体 (0, 1) ではない。λ < 2/5 と 33/50 < λ < 1 は、まだ答えが出ていない。

## 1. 道具の拡張（GeoEncloseReader 0.2.0）

- **λ < 1 への拡張：** B ＝ |L⁻ᵀξ|² の範囲を [min(1, ε²), max(1, ε²)] で包むようにした。λ の箱の端は厳密な有理数で取る。
  - 0.1.0 は B を ≤ 1 で切っていた。そのため扁長族専用だった。
  - λ ≥ 1 の箱では 0.1.0 と同じ値になる。selftest の回帰で確かめた。
- **軸の上の一次元の核：** `ez_axis_bound` と `ezz_axis_bound` を加えた。ρ ＝ 0 では被積分関数が方位によらない。
- **D5 の台帳への接続：** `oblate_d5.py` を加えた。(d, τ, λ) の箱を、子午面の写像で (ρ, z) の包みの箱へ写す。
- **D-OB の値との照合（selftest）：** Reader の参照球の正規化は D-OB と同じである（H_axis が一致する）。

## 3. 軸の上の符号の構造（C-AXIS-V1、V23）

### 3.1 目印

| 目印 | 主張 | Reader |
|---|---|---|
| λ_c | E_zz(0) < 0（λ ＝ 2/5）、> 0（λ ＝ 83/200） | 上界 −0.01485、下界 0.01293 |

| λ_∂ | 極での値 E_z(0, 1) < 0（λ ＝ 5/8）、> 0（λ ＝ 33/50） | 上界 −0.00982、下界 0.00856 |

### 3.2 帯の抜き取り（改訂 A、B）

λ の幅 1/800 の帯ごとに、帯の中点での参照値（mpmath）から根の位置 t_c を予測した。管の半幅は C1 の契約と同じ 1/16 とし、t₋ と t₊ を決めた。そのうえで、各帯で次を確かめた。

- t ∈ [0, 1/16] で E_zz > 0
- [1/16, t₋] で E_z > 0
- [t₋, t₊] で E_zz < 0（根がちょうど一つ）
- [t₊, 1] で E_z < 0。t₊ ＝ 1 のときは、極での値 E_z(0, 1) < 0

根のない相では、次を確かめた。

- λ < λ_c：[0, 1/4] で E_zz < 0、[1/4, 1] で E_z < 0
- λ > λ_∂：[0, 1/16] で E_zz > 0、[1/16, 1] で E_z > 0

| 相 | 帯（左端の λ） | 結果 |
|---|---|---|
| λ < λ_c（根なし） | 2/5 | 帯全体で確認 |
| λ_c < λ < λ_×（根 < 1/2） | 21/50、43/100 | 帯の左端の λ の一点で確認（§3.3） |
| C1b の範囲 [9/20, 5/8] | 9/20、187/400、429/800、91/160、93/160、121/200、123/200、499/800 | 8 本とも帯全体で確認。右端の 4 本は、極での値で右の壁を確かめた |
| 帯の側、λ < λ_∂ | 63/100、16/25（根は 0.994、0.9987） | 帯全体で確認 |
| λ > λ_∂（根なし） | 13/20、527/800 | 帯全体で確認 |

改訂 A では、1 か所（λ ＝ 9/20 の帯、[1/16, 3/32] で E_z > 0）の値が約 0.007 しかなかった。ここは同値な形「E_zz > 0 on [1/16, 3/32]（下界 0.070）と E_z(0) ＝ 0」で示した（改訂 A2）。

### 3.3 λ_c のすぐ上の 2 本の帯（改訂 B2〜B4）

**状況：** λ ＝ 21/50 と 43/100 の帯では、37 区間のうちそれぞれ 8 区間と 6 区間が、帯全体では確認できなかった。

- E_z の値は 2×10⁻³〜9×10⁻³ しかない。O(1) の項どうしの相殺である。
- そのため、λ の幅 1/800 の球の演算だけで約 3×10⁻³ を失う（`V52B4_diag.txt`）。
- 参照値で符号が逆の区間は一つもない。

**試したこと：**

- **B2：** t を 1/2048 まで細かく分けた。約 25 分たっても一区間も終わらず、止めた。
- **B3：** t について平均値形式を使い、λ は帯全体のまま評価した。最初の 2 区間が失敗し、止めた。
- **B4：** 同じ 14 区間を、帯の左端の λ の一点で、t についての平均値形式で確かめた。**14/14 で確認できた。**

**評価：** この 2 本は、λ の一点での確認にとどまる。帯全体で確かめるには、λ についての平均値形式が要る。あるいは、D-OB の C0 のような三階微分による論法（g_ttt < 0 と Φ）を Reader に加える必要がある。

D-OB 自身は、この領域を C0 で示している。Reader の照合が弱いのは道具の側の限界であり、D-OB の結論への反証ではない。

## 4. 照合していないもの（範囲の明示）

- **c₃ < 0（中心の三次の係数）と C0 の g_ttt < 0：** Reader には三階微分の核がない。
- **台帳の再生：** C1b の本走の台帳は研究用 PC にあり、リポジトリにはない。今回は台帳の葉を再生せず、同じ主張を抜き取った λ の帯で独立に導き直した。
- **全数の照合：** D5 の全 28,385 葉（V4 16,640 葉と Plan B 11,745 葉）は照合していない。抜き取りだけである。
- **窓の外：** λ ∉ [2/5, 33/50] は、D-OB の範囲の外である。
