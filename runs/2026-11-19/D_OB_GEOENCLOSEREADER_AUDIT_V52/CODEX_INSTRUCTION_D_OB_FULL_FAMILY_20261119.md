**単発の依頼である。** 方法、道具、分量は自由である。守ってほしいのは §6 だけである。

## 1. 目的

体積を保つ扁平の回転楕円体の族について、停留点の構造を λ ∈ (0, 1) の全体で閉じること。内部と境界の両方を含める。

扁長族はあなたの仕事（V49、V50、V51）で λ ∈ (1, ∞) の全体が閉じた。扁平族も閉じれば、回転楕円体の族の答えが λ ∈ (0, ∞) で揃う。

## 2. 現在の状態

### 2.1 採用済みの範囲：λ ∈ [2/5, 33/50]（D-OB、Judge V24。chat V52 で独立に照合済み）

内部の停留点は、すべて回転軸の上にある。

| λ | 内部の停留点 |
|---|---|
| 2/5 ≤ λ ≤ λ_c | 中心だけ |
| λ_c < λ < λ_∂ | 中心と、軸の上の対 ±t*(λ) |
| λ_∂ ≤ λ ≤ 33/50 | 中心だけ |

- λ_c ∈ (2/5, 83/200)（≈ 0.40796）で、中心での超臨界のピッチフォークが起きる（c₃ < 0）。
- λ_∂ ∈ (5/8, 33/50)（≈ 0.6435）で、軸の上の対が両極から境界へ抜ける。
- 中心の型：λ < λ_c では軸方向が負の鞍、λ > λ_c では極小である。
- 境界の条件 B は、まだ定めていない。

### 2.2 空いている範囲

- **λ ∈ (0, 2/5)：** 円板に近づく側である。λ → 0 の尾を含む。
- **λ ∈ (33/50, 1)：** 球に近づく側である。

非区間の診断（2026-08-31、子午面の走査と軸の行の census）では、次の見込みである。証明ではない。

- λ < λ_c：中心の鞍だけ
- λ > λ_∂：中心の極小だけ
- 軸の外の停留点は、λ ∈ {0.30, 0.50, 0.60, 0.65, 0.80, 0.95} のどれでも検出されなかった。

## 3. 使える道具

- **式：** 参照球 |q| ≤ 1、L ＝ diag(1, 1, λ) の正規化と、式 (2)–(4)、(9) は λ < 1 でもそのまま成り立つ。D-OB の H_axis と同じ正規化である。
  - B ＝ |L⁻ᵀξ|² ∈ [1, λ⁻²]
  - C ＝ |Le|² ∈ [λ², 1]
  - γ ∈ [0, 1]
- **chat の GeoEncloseReader 0.2.0（V52）：** λ < 1 の核と、軸の上の一次元の核を持つ。監査はこれで行う。
  - 軸の上では、被積分関数が方位によらない。一次元の分割で狭く包める。
  - λ_c のすぐ上では、E_z が 10⁻³ 程度の相殺になる。λ の幅についての球の演算だけで、余裕を失った。平均値形式か、三階微分による論法が必要になる。
- **あなたの V50 と V51 の束：** 弦の表示、被覆と検査器の形式、境界のトレースの連続性の論法（支配収束）。

## 4. 考えてほしいこと（制限なし）

1. **λ ∈ (33/50, 1)：** V51 の [1, 2] と同じ型の議論が使えるか検討すること。
   - 赤道の単調性
   - z ≠ 0 での E_z/z の符号
   - λ → 1⁻ の球への一様な扱い
   
   扁平の側では、λ > λ_∂ で軸の上の符号は E_z/z > 0 になる見込みである。
2. **λ ∈ (0, 2/5)：** 次を示すこと。
   - 軸の外：H > 0
   - 軸の上：E_z/z < 0。中心は鞍で、軸方向が負である。
   
   **λ → 0 の尾が本題である。** 円板の極限では、縁（赤道）に特異な層ができる。尺度を合わせた変数か、λ → 0 の一様な漸近で、有限の λ₀ から下を解析で閉じること。残る [λ₀, 2/5] は区間の被覆で覆う。
3. **境界の条件 B：** 扁長と同じ (A) とする。内側から延長した全勾配のトレースが零になる集合を分類すること。
   - λ ＝ λ_∂ で、両極に零が現れる見込みがある。扁長の λ_b で赤道に現れたのと対になる。これを確かめること。
   - 窓 [2/5, 33/50] の中の境界も含めること。
4. **まとめ：** λ ∈ (0, 1) の全体で、停留点の構造の表を作ること。中心の型、軸の上の対、境界の零集合、臨界値を含める。可能なら、扁長の表とつないで (0, ∞) の表にすること。
