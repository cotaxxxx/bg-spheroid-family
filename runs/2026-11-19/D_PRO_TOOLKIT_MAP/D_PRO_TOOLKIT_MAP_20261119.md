# 道具の地図：D-PRO（扁長）で作った道具の、使える範囲と前提

2026-11-19 / 作成：chat ／ 扱い：研究ノート（証拠ではない）／ 第 2 版（記号 A1 の重複を解消、状態を四段階に分離、B1 の仮定を厳密化、補題 I–III を追加）

> 一つの問題の解答より、次の問題を解くための道具を残す。

この表は、道具ごとに次の四つを書く。

- **何をするか**
- **何を仮定しているか**
- **何を仮定していないか**（ここが、使い回せる範囲を決める）
- **確かめた状態**

三軸の楕円体や扁平の側に持っていくときは、「仮定していること」の列が、そのまま確認表になる。

## 共通の記号

参照球の座標は q ＝ (ρ, z)、物理座標は p ＝ (ρ, λz)、ε ＝ 1/λ とする。
μ ＝ ξ_z、s ＝ √(1 − μ²)、S ＝ √(1 − z²)、χ ＝ S²、v ＝ μ − z とする。

```text
k ＝ 1 − zμ − ρ s cos φ
A ＝ s² ＋ ρ² − 2ρ s cos φ
d² ＝ v² ＋ ε²A
B ＝ s² ＋ ε²μ²
γ ＝ εk/(d√B)
F(y) ＝ π²/4 − arccos² y
E ＝ π²/4 − (1/4π)∫ k F(γ) dΩ
```

**記号の注意：** この地図の道具の番号（K1、B4 など）は、報告の式番号とは別である。内部の C² 剰余の仮定は、Astra の Λ₀ 報告では (A1) と呼ばれている。この地図では、混同を避けるため、出典の **P10** で呼ぶ。

- **導出：** 誰が式を導いたか
- **手で確認：** chat が導出を独立に追ったか

## 次の目標：独立した補題として取り出す

D-PRO の全体を知らなくても使えるように、三つの補題に切り出す。それぞれ「仮定、結論、証明、適用例、使えない条件」を書く。

### 補題 I：符号保存型の積分下界

- **仮定：** 被積分関数が P·[c₁ φ₁(y) ＋ c₂ φ₂(y)] の形をしている。P > 0 で、各 φᵢ には上下の評価 φᵢ ∈ [ℓᵢ(y), uᵢ(y)] がある。
- **結論：** 被積分関数 ≥ P·Σ[cᵢ⁺ℓᵢ − cᵢ⁻uᵢ]。この形のまま、区間計算で積分を包める。
- **適用例：** B1（φ₁ ＝ F/y、φ₂ ＝ F′）と B4。
- **使えない条件：** P の符号が不明な場合。cᵢ が φᵢ と同じ変数に強く依存して、相関を失うと包絡が粗くなる場合。

### 補題 II：移動特異層における輸送と相殺

- **抽象形（核によらない）：** f ≥ 0 とし、T ＝ ∂_z ＋ ∂_μ とする。I ＝ −∂_z f ＝ ∂_μ f − Tf である。帯 [z − h, z ＋ h] で −Tf ≥ 0 なら、帯の上の μ 積分は −f(z − h) 以上になる。
- **楕円体の部分：** 帯の幅 h ＝ S²/4、S ≥ 4ε のもとで、−Tf ≥ γF′C、C > 0 を示す（C1、(G12)–(G15)）。
- **使えない条件：** 一般の核で −Tf ≥ 0 を示す方法は、まだない。特異点が z に沿って平行移動しない核では、T を作り直す必要がある。

### 補題 III：解析的排除と区間計算を組み合わせた停留点不存在判定

- **仮定：** 領域を有限個の部分に分ける。各部分で、勾配のある成分の符号を一つ示す。例えば H < 0、E_z > 0、(C21) の W ≠ 0 などである。根拠は解析でも区間計算でもよい。
- **結論：** 内部に、中心以外の停留点はない。
- **台帳の規則：**
  - 各部分の面積を、判定の種類ごとに一度だけ数える。
  - 和が全体になることを有理数で確かめる。
  - 境界は条件 B として別に扱う。
- **適用例：** R63_T63（E_z > 0 で排除、H は未判定）と、重い板の集計スクリプト。
- **使えない条件：** 部分の境目にちょうど停留点がある場合。閉じた部分で符号を示す必要がある。
