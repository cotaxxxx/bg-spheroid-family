## 3. 前回の道具の実測（Dig の診断、λ ＝ 5）

U₂₀ の区間の評価を、事前に固定した計画で測った。

| 実験 | 結果 |
|---|---|
| A：点 (ρ, z) ＝ (0, 0) | 中心は成功。包囲 [−0.0264, −0.0222] |
| A：点 (1/2, 0)、(1/2, 1/2) | 上端 < 0 を示せず。包囲 [−0.235, ＋0.077]、[−0.306, ＋0.012] |

| B：既存の箱 R45_T01 で、現行 (C21) の評価器の密度だけを U₂₀ に差し替え | 半幅は 0.0163 → 5.61（345 倍）、時間は 369 秒 → 435 秒。幅の大半は二階の補正（5.607）。特に x_x、R_x、x_λ の Hessian の補正が大きい |

**読み方：**

- 失敗は符号の問題ではなく、包み方の問題である。
- 素朴なセルの値域 × 面積は、D⁻⁵ を含む核で、μ ＝ z と接触の近くで膨らむ。
- 現行の (C21) の評価器は、有理 Taylor モデル（K ＝ U/(R²δs)、q ＝ λ⁻² の多項式、優級数の剰余、形式的な割り算）で相関を保っている。U₂₀ を区間で直接評価すると、二階微分の段階で相関を失う。

## 4. 考えてほしいこと（制限なし）

1. **λ ≥ 5 を有限の箱に移す。** 極の (G1) と同じく、ε ＝ 1/λ ∈ [0, 1/5] を変数にし、ε ＝ 0 を連続な極限として含める。
   - 非極では主要項に log λ が入る。そのため、正規化した量を使う必要がある。例えば λH/(1 ＋ log λ) と λE_z/(z(1 ＋ log λ)) で、ε → 0 ではそれぞれ −πS と 3πS に向かう（(G29)、(G30)）。
   - 変数に (ε, 1/(1 ＋ log λ)) を使う、などの工夫が要るかもしれない。ε ＝ 0 での正則性と、剰余の形を明らかにすること。
2. **尺度を合わせた変数。** λ が大きいと、核は帯 |μ − z| ≲ 1/λ に集中する。μ − z ＝ εt と拡大すると、帯の中は ε について正則になり、帯の外から log が出る、という分け方が考えられる。極の (G12)–(G15) の輸送 T ＝ ∂_z ＋ ∂_μ も使ってよい。
3. **相関を保つ包み方。** 符号付きの積分を、相関を保ったまま包むこと。§3 の失敗を繰り返さないこと。有理 Taylor モデル、輸送、部分積分などの方法は自由である。
4. **軸。** 非極の軸の上の E_z/z > 0 を、λ に一様に示すこと。(G4) の E_z の核、あるいは軸に特化した一変数の積分を使ってよい。
5. **計算機との分担。** 有限の箱の被覆が必要なら、箱の数、精度、時間の見積もりを出すこと。今の研究用 PC は 12 プロセスで、重い板 1 枚（λ の幅 1/16）に約 1 日かかっている。
