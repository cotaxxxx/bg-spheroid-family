## 3. 論理の手による確認

### 3.1 [1, 2] の内部

- **z ≠ 0：** 赤道での反射から E_z(ρ, 0) ＝ 0 である。
  - z ≤ 1/4 では、縦の線分の上で E_zz ≥ 66330426/2³⁶ を積分する。
  - z ≥ 1/4 では、E_z ≥ 16189/2³⁶ と z ≤ 1 を使う。
  - したがって、z ≠ 0 で E_z/z ≥ 16189/2³⁶ > 0 である。これには軸 ρ ＝ 0 も含まれる。正しい。
- **赤道 z ＝ 0、ρ > 0：** g(ρ) ＝ E_ρ(ρ, 0) ＝ ρH とおく。g′ ＝ E_xx である（(6) の E_xx ＝ H ＋ ρH_ρ）。
  - `H_positive` の葉では g > 0 である。
  - 残りの葉では g′ < 0 である。各 λ でこの葉は ρ ＝ 1 まで続く。したがって、そこでは g(ρ) > lim_{ρ→1} g ＝ H_b > 0 である。
  - よって、赤道に零点はない。報告書の言い方（一度負になってから戻る、という議論）よりも、**単調性から直接に従う。** 結論は同じである。
- **中心：** Hessian は diag(H, H, E_zz) で、各成分は正である。したがって非退化な狭義極小である。

### 3.2 境界のトレース

- E_i ＝ ⟨ξ_i J − L_ii √B u_i K⟩ は、(2) と同じ微分で得られる（k_i ＝ −ξ_i、D_i ＝ −L_ii u_i）。chat が導き直して一致した。
- J ＝ γP − arccos²γ と K ＝ γ²P は、[0, 1] で連続かつ有界である。また √B ≤ 1、|u| ＝ 1 である。
- 被積分関数は、q と ξ について一様に有界である。q → q₀ のとき、ξ ≠ q₀ の各点で収束する。
- 支配収束から、∇E は閉球で連続に延長される。延長は近づき方によらない。したがって、内部で一様な不等式は、非厳密な形で境界へ移せる。
- **注意：** 正しい。ただし、厳密な不等式をそのまま移せるわけではない。使われているのは「E_z/z ≥ c > 0」と「√(λ² − 1)H < −2⁻¹⁷」のように、**定数による余裕がある形**だけである。この点も確かめた。

### 3.3 境界での各範囲

| 範囲 | z ≠ 0（両極を含む） | 境界赤道 z ＝ 0 |
|---|---|---|
| [1, 2] | E_z/z ≥ c > 0（c ＝ 16189/2³⁶）。北半球で E_z > 0、南半球で E_z < 0。いずれも E_z ≠ 0 なので、全勾配は零にならない（訂正 E1、E3） | 全勾配 ＝ H_b e_ρ。H_b > 0（chat 9/9） |
| [2, 5] | V50 (5)：E_z/z ≥ 3341881/2³⁶ | V50 (9)：H_b の零は λ_b だけ |
| [5, ∞) | 非極：E_ρ ≤ −ρ2⁻¹⁷/√(λ² − 1) < 0（V49 の不等式は全内点で成り立つ）。両極：V48 L2 の E_z/z ≥ 3/(10λ²) を軸に沿って移す | 非極に含まれる |

- λ_b ちょうどでは、内部に円はない。円は右側から境界赤道へ縮んで入る（V50）。表の λ_b の行と整合する。

## 4. Judge に判断してもらう点：条件 B の定義

**(A) 推奨：全勾配のトレースが零になる集合を、条件 B とする（Codex の推奨と同じ）。**

- 私の指示書の言葉（「内側のトレースとしての勾配」）に合う。
- 意味もはっきりしている。境界は、内部の停留点が集まる先としては、λ_b の赤道を除いて現れない。
- 未分類の部分は残らない。

**(B) 別案：境界に制限した接線方向の停留（KKT 型）を求める。**

- 対称性から、両極と境界赤道はすべての λ で、自動的に接線方向の停留集合に入る。
- 法線方向の符号は、すでに分かっている。両極では E_z/z > 0 である。北極では E_z > 0、南極では E_z < 0 で、どちらも外向きである（訂正 E1）。境界赤道では H_b の符号で、λ < λ_b なら外向き、λ > λ_b なら内向きである。
- ただし、それ以外の緯度に接線方向の停留点がないことは、まだ示されていない。新しい計算が要る。

**推奨は (A) で答えを閉じることである。** (B) は、閉じた球の上での変分問題という別の問いとして、次の課題に記録しておく。

**裁定済み：** Judge は (A) を採用した（`JUDGE_RULING_PROLATE_FAMILY_ADOPT_20261119.md`、commit `6e6b9af`）。
