## 結論（先に）

1. **L2 は正しいと見てよい。** λ ≥ 5、|z| < 1 の軸の上で E_z(0, z)/z ≥ 3/(10λ²) が成り立つ。
   - S ≥ 1/λ の部分は (16)–(18)。
   - S < 1/λ の部分は (G1) で示される。
   - z ＝ 0 では E_zz(0, 0) への連続な延長になる。
   - 証明の核心は二つある。子午角 a の移流恒等式 (14) と、反射対の積の因数分解 (16)。それに、角度の和の符号の恒等式 sin Σ ＝ 2εμs(S² − ε²)/(B√(L₊L₋)) (17) である。
   - S ≥ ε なら Σ ≥ 0 になり、被積分関数は各点で正である。
2. **L1 は、λ ≥ 4096 で正しいと見てよい。**
   - **L1-A：** S ≥ 2⁻¹²、0 < ρ < S（接触は内側からのトレース）で R_H^(2)/S ≤ 29/2。
   - **L1-B：** ∂_λT_λ > 0 と、T_4096 ≥ 149π/32 > 29/2。
   
   したがって、非極の全域で H < 0 である。
3. **組み立て：λ ≥ 4096 で、Ω ∖ {0} に停留点はない。** 次の四つを合わせる。
   - 極の (G21)：λ ≥ 5（V43 と、その訂正）
   - 中心の H(0) < 0（V45）
   - L1
   - L2
   
   **A1 を仮定しない、有限で明示的な Λ₀ ＝ 4096 が初めて得られた。** 中心は、横の二方向が負、縦が正の鞍点である。
4. **実用には遠い。** [5, 4096] を今の (C21) で覆うと、約 65,456 日かかる。窓と接続するには、L1 を λ ≈ 5〜10 まで下げることが必要である。L2 はすでに λ ≥ 5 で使える。
5. **副産物：L2 の S ≥ 1/λ の部分は λ ≥ 2 でも成り立つ。**
   - (16)–(18) は ε ≤ 1/2 で成り立つ。(18) の分母の評価が 9/4 ＋ 1/4 ＝ 5/2 のまま通る。
   - つまり窓 [2, 5] でも、軸の上の S ≥ 1/λ では E_z/z ≥ 3/(10λ²) が解析的に従う。
   - 残るのは極の帽子 S < 1/λ だけである。(G1) の区間下界は、λ ≥ 80/19 ≈ 4.21 で正になる（V43 の診断）。
   - 窓の被覆で、軸の条件をどう扱っているかを照合すれば、計算を減らせる可能性がある。
