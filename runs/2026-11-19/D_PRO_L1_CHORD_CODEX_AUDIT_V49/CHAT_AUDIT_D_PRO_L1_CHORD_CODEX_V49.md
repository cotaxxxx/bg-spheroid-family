## 結論（先に）

**命題 (1) は正しいと見てよい。** λ ≥ 5 なら、参照球のすべての内点で √(λ² − 1) H < −2⁻¹⁷ が成り立つ。三つの部分に分けて確かめた。

1. **λ ≥ 8、すべての q：** 有限の被覆に依存しない。chat は導出を手で追い、自分の Arb の計算で定数を再現した。
2. **λ ≥ 5、S ≤ 1/λ（極の側）：** 同じ一次元の評価から √(λ² − 1) H < −7/50。chat の Arb の計算で再現した。
3. **5 ≤ λ ≤ 8、S ≥ 1/λ：** 有限の箱の被覆による。次の三つで確かめた。
   - Codex のコード一式を新しいディレクトリで再実行した。表と台帳 3 枚がバイト単位で一致した。

   - 全 1,845 葉を独立に計算し直したわけではない。

**組み立て：** L1（今回）に、L2（V48、λ ≥ 5 の軸）と中心の対称性を合わせる。

> **λ ≥ 5 では、内部の停留点は中心の鞍点だけである。**

中心の鞍点は、横の二方向が負、縦が正である。(G21) と (G1) の極の補題は、この組み立てにはもう要らない。(3) の評価が極の側も直接覆うからである。
