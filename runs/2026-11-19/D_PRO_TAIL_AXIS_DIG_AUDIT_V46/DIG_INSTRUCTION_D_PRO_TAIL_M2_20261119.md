## 1. 目標

明示的な数 Λ₁ を出し、λ ≥ Λ₁ で次の二つを示すこと。

- **(T1) 非極：** S ＝ √(1 − z²) ≥ S₀ ＝ 2⁻¹²、0 < ρ < S（接触の近くを含む内部）で H < 0。
- **(T2) 軸：** ρ ＝ 0、S ≥ S₀、z ≠ 0 で E_z/z > 0。

これに、すでに監査済みの部品を合わせる。

- 極：(G21)、λ ≥ 5
- 中心：H(0) < 0、λ ≥ 5

そうすれば、**λ ≥ Λ₁ で Ω ∖ {0} に停留点はない。** 残る [5, Λ₁] は、その後に区間計算で覆う。

Λ₁ は小さいほどよいが、まず有限で明示的な値を出すことを優先する。現実的な値と、それを決めている定数を表で示すこと。

## 3. 考えてほしいこと（方法は自由）

1. **領域の分け方。** 次の二つに分けることを推奨する。
   - コンパクトな内部 K_m ＝ {|q| ≤ 1 − m} ∩ {S ≥ S₀}
   - 接触カラー 1 − m < |q| < 1
   
   m は λ に依存してよいが、明示すること。
2. **K_m での R_H^(2) の一様な上界。** 次の不等式を示す定数 C(m, S₀) を、証明つきで出すこと。
   ```text
   R_H^(2) < (πS/2)Σ asinh − (3S²/2)Σ atan
   ```
   - 例えば、t を内側 |t| ≤ T₀ と外側 |t| > T₀ に分ける方法がある。内側は ε についての正則性と Taylor 剰余で扱う。外側は、O(|t|⁻³) の定数を K_m と ε について一様に出す。
   - ε → 0 と |t| → ∞ の順序を交換しないこと。
   - t₊、t₋ は ε⁻¹ で発散するので、外側の積分は別に評価すること。
3. **接触カラー。** (NP10) で、K_m の内側の点 ρ′ の負の余裕 h* から運ぶ。
   - 運べる距離は Δρ < λρ′h*/(2T_λ) である。
   - λ が中くらいのときは T_λ が大きく（S₀ では約 20）、Δρ が小さくなる。m と h* と Λ₁ の関係を明示すること。
   - 必要なら、δ ＝ 1 − |q|² などの多尺度の変数を使ってよい。
4. **軸（T2）。** 奇の差商 [I(μ, z) − I(μ, −z)]/z を、共通の分子のまま扱うこと。差し引いてから z で割ると幅が発散する（M1 の §5）。
   - 正規化した λE_z/(z(1 ＋ log λ)) は 3πS に向かう。その下界を λ に一様に示すこと。
   - z → 0（E_zz(0, 0)）への連続な延長も扱うこと。
5. **相関を保つ包み方。** U₂₀ を区間で直接評価すると相関を失った（Judge は不採用）。区間計算の試作を作る場合は、同じ失敗をしない形にすること。
