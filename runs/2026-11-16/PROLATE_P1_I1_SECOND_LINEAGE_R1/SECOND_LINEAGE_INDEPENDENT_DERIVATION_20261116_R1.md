## 1. 境界の固定領域への引き戻し（R1再計算）

λ>1 とする。単位球面の点 ξ=(u,v,w)=(√(1−w²)cosφ,√(1−w²)sinφ,w) に対し、線形写像 T=diag(1,1,λ) を用いて境界を X=Tξ=(u,v,λw) とパラメータ化する。−1≤w≤1、0≤φ≤2π、dΩ=dφ dw である。極の座標特異性は測度零であり、以下の積分に影響しない。

**(1) 面積要素。** 球面の接ベクトル ξ_w, ξ_φ を取ると、(Tξ)_w×(Tξ)_φ=det(T)T^(−T)(ξ_w×ξ_φ) である（行列式と外積の恒等式）。|ξ_w×ξ_φ|=1、ξ_w×ξ_φ は符号を除いて ξ に等しい。従って

 dA=|det T| |T^(−T)ξ| dΩ=λ √(u²+v²+w²/λ²) dΩ=λ n dΩ,
 n:=√(1−w²+w²/λ²)>0.

**(2) 外向き単位法線。** 楕円体の境界は f(x,y,z)=x²+y²+z²/λ²−1=0。∇f(X)=2(u,v,w/λ)。よって N=(u,v,w/λ)、|N|=n、ν_λ(X)=N/n である。特に X·N=u²+v²+w²=1。

**(3) 積の簡約。** B(p):=(X−p)·N=1−p·N とすると

 [(X−p)·ν_λ(X)]dA=[B(p)/n] [λ n dΩ]=λ B(p)dΩ.

法線の分母 n と面積要素の n が完全に相殺され、積には n は残らない。ただし角度の余弦 c(p)=B(p)/(n D(p))、D(p)=|X−p| の分母には n が残る。

**(4) 全体の前の因子。** Vol(K_λ)=det(T)Vol(B³)=λ(4π/3)。したがって 3Vol(K_λ)=4πλ。定義に代入して

 E_λ(p)=[1/(4πλ)]∫∫ α² λ B(p)dΩ
       =[1/(4π)]∫_{−1}^1∫_0^{2π} B(p) A(B(p)/(nD(p))) dφ dw,
 A(c):=(arccos c)².

**R1修正の核心：** 旧稿の E の積分核に誤って掛かっていた n を削除した。n は c の分母には必要だが、積分核の外側の乗数には現れない。

## 2. 明示的な積分表現

S=1+(λ²-1)w², n=sqrt(1-w²+w²/λ²), u=sqrt(1-w²)cosφ, b=w/λ, d=λw とする。任意の変数 t について

F_e(t;λ,w,φ)=(1-tu) A((1-tu)/(n sqrt(S-2tu+t²))),
F_a(t;λ,w,φ)=(1-tb) A((1-tb)/(n sqrt(S-2dt+t²)))。

[t^k] は t=0 の Taylor 係数（1/k! 倍の k 階導関数）を表す。すると、いずれも有限区間上の厳密な定積分として

Q(λ)=(2/(4π))∫∫[t²]F_e(t;λ,w,φ) dφ dw,
H₄(λ)=(24/(4π))∫∫[t⁴]F_e(t;λ,w,φ) dφ dw,
Q_z(λ)=(2/(4π))∫∫[t²]F_a(t;λ,w,φ) dφ dw,
Q′(λ)=(2/(4π))∫∫[h t²]F_e(t;λ+h,w,φ) dφ dw。

積分範囲はすべて w∈[-1,1], φ∈[0,2π]。[h t²] は h と t に関する二変数 Taylor 展開の係数である。これらは「微分を残した定義」ではなく、指定次数の有限 Taylor 係数を被積分関数とする代数的に評価可能な表現である。特に Q′ は参照体 λ 微分であり、体積保存座標の微分ではない。

二階係数をさらに展開する。c₀=1/(n sqrt S), A_j=A^{(j)}(c₀)。任意の B(t)=1-βt、D(t)=sqrt(S-2γt+t²) に対し

c₁=(γ/S-β)/(n sqrt S),
c₂=(-1/S+3γ²/S²-2βγ/S)/(n sqrt S),

ここで c₁=c′(0), c₂=c″(0)。積分核 B(t)A(B(t)/(nD(t))) の二階導関数は

G₂(β,γ)=A₂ c₁² + A₁ c₂ −2β A₁ c₁。

従って Q(λ)=(1/(4π))∫∫G₂(u,u)dφdw、Q_z(λ)=(1/(4π))∫∫G₂(w/λ,λw)dφdw。Q′(λ)=(1/(4π))∫∫∂_λ G₂(u,u)dφdw とも書ける。この最後の λ 微分は以下の有限代数規則で完全に定義される：∂λ S=2λw²、∂λ n=−w²/(λ³ n)、∂λ c₀=−c₀(n_λ/n+S_λ/(2S))、∂λ A_j=A_{j+1}∂λ c₀、そして G₂ の積・商・連鎖律。u と w と φ は λ に依存しない。

四階積分核を明示的な有限演算で与えるには、環 R[t]/(t⁵) 内で

P(t)=(S-2ut+t²)^{-1/2} mod t⁵,
C(t)=(1-tu)P(t)/n mod t⁵,
F(t)=(1-tu)∑_{j=0}^4 A^{(j)}(c₀)(C(t)-c₀)^j/j! mod t⁵

と計算し、H₄=(24/(4π))∫∫[t⁴]F(t)dφdw とする。P の係数は (1+x)^{-1/2}=∑_{k=0}^4 binom(-1/2,k)x^k を x=(-2ut+t²)/S に代入して求める。この手順は有限個の四則演算と A の導関数だけで閉じている。A の導関数は次節の解析関数から一意に得られる。

## 3. 微分積分交換と正則性

A(c)=4[arcsin sqrt((1-c)/2)]² と書ける。arcsin(s)² は s=0 近傍で s² の収束冪級数を持つため、A は c=1 を横断して実解析的に延長する。c∈(0,1) では通常の arccos² と一致する。c=-1 での正則性は不要。

λ∈I=[47/10,19/4]、|r|,|z|≤ε とする。ε>0 を十分小さく、例えば ε=1/4 と選べば p はすべての Kλ の内部にあり、B≥3/4>0、D≥3/4>0、n≥1/(19/4)>0 である（|X|≥1、|N|≤1）。境界の凸性から 0<c=B/(nD)≤1。実際、ε を十分小さく取ったコンパクトな (λ,p,w,φ) 全体で c は正の下界を持ち、上界は1である。したがって A と必要なすべての導関数は c の値域の近傍で実解析的で、連続かつ一様有界である。

S、n、B、D はこのコンパクト集合上で分母が零にならない実解析関数であり、合成積分核とその任意の有限階の r,z,λ 偏導関数は連続かつ一様有界。有限測度領域 [-1,1]×[0,2π] では定数関数が可積分な支配関数になる。差商に平均値の定理を適用して支配収束定理により微分を積分内へ移せる。これを反復すると任意の有限階微分の交換が成立する。さらにコンパクト集合上の一様な局所複素解析延長と Cauchy 評価（有限被覆で半径を共通化）により積分はパラメータについて実解析的である。

I の両端 λ=47/10,19/4 も、I を含む開区間（例えば (4,5)）で同じ議論が成立するため、端点での微分はその開区間からの制限として定義される。よって Q,Q′,H₄,Q_z は端点を含め正則で、上の全ての積分式が成立する。

## 4. 相似不変性と座標

c>0 の一様拡大 X↦cX, p↦cp に対し、角度 α は不変、(X-p)·ν は c 倍、dA は c² 倍、体積は c³ 倍である。従って E_{cK}(cp)=E_K(p)。c=λ^{-1/3} と置くと体積保存体の物理座標での二階導関数は λ^{2/3}Q および λ^{2/3}Q_z、四階導関数は λ^{4/3}H₄ となる。体積保存体の赤道二階係数の λ 微分は λ^{2/3}Q′+(2/3)λ^{-1/3}Q。判定用の Q′ は前節の参照体 Q′ である。
