## 0. 目的

体積を一定に保つ扁長回転楕円体（λ ∈ [2, 5]）について、内部の停留点がすべて赤道面にあることを示したい。そのために使う量は次のとおりである（採用済みの設計：`cotaxxxx/bg-spheroid-family` branch `design/d-pro-global-20261116`、commit `7756bc51`、`drafts/2026-11-16/D_PRO_GLOBAL_DESIGN_ASTRA/D_PRO_GLOBAL_DESIGN_ASTRA_20261116.md` の §1〜§3）。

```text
V(ρ, z; λ) = (1/z) ∂_z E(ρ, 0, z)   (z ≠ 0)、   V(ρ, 0; λ) = E_zz(ρ, 0; λ)
```

V > 0 の区間認証の本走は、あとで行う。今回は次の三つを作る。

- **A（最優先）：** その本走に使う区間積分核と、較正の道具を作る。
- **B：** 解析補題の草稿を書く。
- **C：** 来歴を調べる。

## 1. 定義（この指示書の座標。回転軸を z とする）

**楕円体と基点：**

- 参照体は K_λ ＝ {x² ＋ y² ＋ z²/λ² ≤ 1}（λ > 1）である。
- 境界は x ＝ (ξ_x, ξ_y, λμ) と書く。ここで ξ ＝ (ξ_x, ξ_y, μ) は単位球の点である。
- dΩ は単位球の面積要素である。
- 基点は p ＝ (ρ, 0, z) とする。
- 子午面の座標は ρ ＝ R·a、z ＝ λR·b、a ＝ (1−τ²)/(1+τ²)、b ＝ 2τ/(1+τ²) で、R ∈ [0, 1]、τ ∈ [0, 1] である。

**積分核の量：**

```text
w = √(λ²(1−μ²) + μ²)，  h = λ(1 − ρ ξ_x) − z μ，  D = |x − p|
γ = h/(w D)，  G(γ) = arccos²γ，  R(γ) = arccos γ / √(1−γ²)，  R′(γ) = (γR − 1)/(1 − γ²)
T = (λμ − z)/D，  n = μ/w，  e = γT − n，  γ_z = e/D
E(p)   = (1/(4πλ)) ∫ h G(γ) dΩ
E_z(p) = (1/(4πλ)) ∫ [ −μ G(γ) − 2 h R(γ) γ_z ] dΩ
E_zz(p)= (1/(4πλ)) ∫ (2w/D) [ γ² R (1 − T²) − (2R + γR′) e² ] dΩ
```

**確認済みのこと：**

- 上の式は、chat が独立に検算した（40 桁、200 点）。
- R(γ) ＝ ∫₀^∞ dt/(γ ＋ cosh t) ＝ Σ_{n≥0} c_n (1−γ)^n、c_n ＝ 2^n (n!)²/(2n+1)! である。
- γ ＝ 1 の近くでは、この級数を使う（0/0 の形を避けるため）。
- 球 λ ＝ 1 では、E(p) ＝ f(|p|)、f(r) ＝ (1/2)∫_{−1}^{1} arccos²((1 − rc)/√(1 − 2rc + r²))·(1 − rc) dc である。

**座標の注意：** 扁長側のリポジトリ（`cotaxxxx/basepoint-geometry`）では回転軸を y と書いている。この指示書は z である。

## 2. A：区間積分核（python-flint、Arb）

**流用する元：** 扁平側の D5（H ＝ E_ρ/ρ > 0）で使った、箱の上で積分核を包むコードを流用・移植してよい。むしろそうしてほしい。所在は次のとおりである。

- `cotaxxxx/bg-oblate-spheroid` branch `evidence/d5-planb-run1-20261112` の `analysis/D5_PLANB_ROUND3_20261109/DIG_D5_PLANB_ROUND3_EVIDENCE_20261109.zip` 内の `sources/chat_m22iv.py`、`chat_m40iv.py`、`chat_bprime_iv.py`
- branch `evidence/d5-v4-run1-20261111` の `analysis/D5_V4_RUN1_20261111/V4_RUN1_EVIDENCE_20261111.zip`

扁平の積分核との違いは、回転軸の向き、量（H の代わりに E_z・E_zz・V）、λ > 1 であることの三つである。

**作るもの：** `prolate_p3/kernel.py`。

1. **点の包囲：** `Ezz_ball(rho, z, lam, prec)`、`Ez_ball(...)`、`E_ball(...)`。入力は有理数（`fmpq`）とする。出力は区間（Arb のボール）で、真の値を必ず含むこと。単位球の上の積分は、厳密な誤差の上界つきの求積で行う。例としては、セルごとの Taylor 法と区間の剰余、または Arb の `acb.integral` の入れ子などがある。どの方法を選んだかと、なぜ正しいかを、README に書くこと。
2. **箱の包囲：** `V_box_lower(R_iv, tau_iv, lam_iv, prec)`。V の下界を返す。方法は次のとおりとする。
   - **z の下端が 0 より大きい箱：** E_z の箱の包囲を z の区間で割る。
   - **z ＝ 0 に触れる箱：** V(ρ, z) ＝ ∫₀¹ E_zz(ρ, sz) ds なので、V は {(ρ, sz)：s ∈ [0, 1]} の上の E_zz の包囲に入る。これを使う。
3. **範囲：** 今回は内部 R ≤ 15/16 だけを扱う。境界の近くの接触部分を切り取る処理は不要である。λ ∈ [2, 5] とする。

**対照テスト：** `prolate_p3/tests/`。すべて自動で PASS/FAIL を出すこと。

- **球（λ ＝ 1）：** 5 点以上で、`Ezz_ball` と `Ez_ball/z` の区間が、f′(R)/R と f″ から作った厳密値を含むこと。厳密値は、上の 1 次元の積分を mpmath で 30 桁で計算する。
- **反射：** V(ρ, −z) ＝ V(ρ, z)、E_z(ρ, −z) ＝ −E_z(ρ, z)。
- **差分との一致：** E_z が E の z の中心差分と合うこと。E_zz が E_z の中心差分と合うこと（λ ＝ 3 の 5 点で）。
- **箱の健全性：** 箱の中の 20 点で点の包囲をとったとき、`V_box_lower` がそのすべての下端以下であること。
- **詰まりの防止：** Float の数値の記述を使わないこと。入力はすべて有理数とする。

## 3. A：較正の道具（研究用 PC で流すためのもの）

**作るもの：** `prolate_p3/calibrate.py`。

- **箱の一覧：** 走らせる前に固定して、ファイルに書いておく。λ ∈ {2, 7/2, 5}、R ∈ {1/8, 1/2, 7/8}、τ ∈ {0, 1/2, 1} の各組み合わせの点のまわりに、幅 1/64（R と τ）、1/256（λ）の箱を置く。計 27 箱である。
- **記録する数字：** 精度 128 ビットと 192 ビットのそれぞれで、次を記録する。
  - 1 箱あたりの壁時計の時間（秒）
  - 最大 RSS
  - 下界の区間の幅
  - 求積のセル数
- **出力：** JSON と TSV。V の下界の符号も記録してよい。ただし、`NOT_EVIDENCE` と明記する。この結果を見て箱の一覧や分割を変えてはいけない（診断の規則）。
- **流す場所：** 研究用 PC（Ryzen 9 9900X、12 コア、RAM 約 29 GiB、Ubuntu、python-flint）で流すのは Dig である。Codex は自分の環境で 1 箱だけ流し、動くことを確かめればよい。
