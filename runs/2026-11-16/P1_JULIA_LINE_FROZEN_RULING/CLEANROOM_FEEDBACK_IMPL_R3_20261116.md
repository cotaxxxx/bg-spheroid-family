# 実装への差し戻し（第 3 回）：S1 を書き切ること

対象：S1 R3 のソース一式（zip の SHA-256 `de991589ba5843094d512734038955adfaa568f11b49b92233526dd1a18950c0`）

## 1. 役割の区別（大事な点）

- **あなたの仕事：** S1 の実装を、動くコードとして最後まで書き切ることである。
- **chat の仕事：** 正しさの証明（jet の包囲、剰余、丸め、保証の印）を I3 で監査することである。
- **止めるもの：** 契約にある「停止」は、認証の判定（PASS や CERTIFIED の出力）を出さないという意味である。証明が済んでいないことを理由に、コードを書くのを止めてはいけない。
- **書き方：** 自分で正しさに確信が持てない処理も、そのまま書くこと。その箇所には、注釈として「この包囲が正しい理由」と「確信が持てない点」を書いておくこと。

## 2. S1 で、全部書いてほしいもの

| 部品 | 中身 |
|---|---|
| Ajet | 区間を入力にとる。c ＝ 1 の近くは、R1 §3 の冪級数と、その打ち切り誤差の上界で包む。c ＝ 1 から離れたところは、通常の合成で包む。二つの切り替えの規則も書く |
| 被積分関数の jet | R3 で導いた滑らかな座標のもとで、Q の被積分関数の n＋1 次までの jet を、区間のセルの上で計算する |
| セルの求積 | 契約 Q3 の式で、各セルの積分の包囲を出す。剰余 R ＝ 2B h^{n+2}/(n+2)!、B ＝ (n＋1)!·sup\|c_{n+1}\| とする |
| π とヤコビアン | 契約 Q2 のとおりに扱う |
| 台帳 | 契約 Q5 の検証票の形式で、各セルの有理数の端点を書き出す |
| checker | 台帳を読み、`Rational{BigInt}` だけで、被覆、剰余、π、和、門の符号を計算し直す |
| 動作検査の入口 | `run_s1_smoke(λ_lo, λ_hi)` のような関数。一つの λ の箱で Q の包囲を出して台帳に書く。認証の判定はしない |

## 3. 返してほしいもの

- 動くと考えるソース一式（長くなる場合は、ファイルを分けてよい）
- 各ファイルの SHA-256
- 注釈の一覧（確信が持てない点）

これを受け取ったら、研究用 PC で動作検査を流し、エラーがあればその内容だけを返す。

入力は、これまでどおり pack V2、契約、差し戻しだけとする。
