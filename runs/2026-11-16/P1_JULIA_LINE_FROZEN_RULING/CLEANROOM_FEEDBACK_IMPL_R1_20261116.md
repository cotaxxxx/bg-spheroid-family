# 実装への差し戻し（第 1 回）

対象：封印済みの `producer.jl` と `checker.jl`（現在の版）

この差し戻しは、研究用 PC の専用の Julia 環境での動作検査だけに基づいている。ほかの資料の式や数値は含まない。

## 1. エラー

Julia 1.10.13 と IntervalArithmetic.jl 1.0.10 で `invjet` を検査したところ、次のエラーが出た。

```text
UndefVarError: `contains_zero` not defined
```

IA 1.0 で区間が点を含むかを判定する正式な関数は、`in_interval(0, x)` である。研究用 PC で動作を確かめ済みである。

## 2. 次の版でそろえてほしいもの

封印済みの原本は変更しないこと。新しい版を作り、SHA-256 で封印し直すこと。次の版では、未完成の部分をすべてそろえてほしい。

1. 1. のエラーの修正。`contains_zero` を使っている箇所をすべて `in_interval` に置き換える。
2. `Ajet`（A(c) ＝ (arccos c)² の Taylor jet）。
3. Q、Q′、H₄、Q_z の 4 つの積分の評価。
4. 各セルでの Taylor 剰余の上界 B の証明と、その計算。
5. `Rational{BigInt}` だけで、台帳から被覆・剰余・π・和・門の符号を計算し直す checker。

## 3. 進め方

- 動作検査は研究用 PC の側で行い、エラーの内容だけを返す。
- 返してほしいものは次のとおりである。
  - 新しい版のソース一式
  - 変更点の一覧
  - SHA-256 の一覧
- 入力は、これまでどおり pack V2、検証つき積分の契約、この差し戻しだけとする。ほかの資料を検索したり参照したりしないこと。
