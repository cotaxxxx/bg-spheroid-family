## 3. I3：積分契約に要る直し（V2）

- **J3（Taylor の演算）：** Q3 の h_g^{(j)}(m, Λ) と B_{I,Λ,n+1} を得るには、区間係数の Taylor 演算（jet）が要る。IntervalArithmetic.jl 単体には、この機能がない。次のどちらかに決めて固定する。
  - (a) TaylorSeries.jl を追加し、版を Manifest に固定し直す。
  - (b) 切り詰めた Taylor 演算を、Interval{BigFloat} の上で自前で実装する。chat が監査する。

  chat の推奨は (b) である。小さく、監査しやすく、依存も増えない。
- **J4（IA 1.0 の保証の印）：** IA 1.0 では、Float64 の数値（例：`0.1`）や非区間の数が混ざると、結果に「保証なし」の印（NG）が付く。次を契約に入れる。
  - 入力はすべて有理数（`Rational{BigInt}`）から区間を作る。
  - 浮動小数の数値の記述を禁止する。
  - 最終の判定に使う区間は、すべて `isguaranteed` が true であることを確かめる。
  - BigFloat での基本関数（sqrt、acos など）の外向きの包囲は、MPFR の向きつき丸めによる。このことを、小さな対照の例で実証する（既知の有理数の点で、真の値を含むか）。
- **J5（checker の定義）：** Q5 の「別実装の interval 演算」を、次のように具体化する。checker は、producer の台帳に記録した有理数の端点・Taylor 係数の包囲・剰余の上界から、セルの被覆、剰余の式、π の上下界、最終の和と門の符号を `Rational{BigInt}` で厳密に計算し直す。被積分関数を計算し直すことは求めない。これは扁平の空白② の検収と同じ型である。
- **J6（担当）：** I0 と I2 は Astra ではなく chat が行う。
  - I0 は本記録で済んだ。
  - I2 は、導出した式と第一系統の積分核の記号同値性の照合である。chat は第一系統を読めるが、実装者に数値も式も渡さない。そのため独立性は保たれる。外部への依頼を増やさないためにも、この形がよい。
- **補足（任意）：**
  - Q1 の「一変数積分 ∫₀^{π/2}」という形の指定は、第一系統の形を示唆する。導出の形は実装者に任せ、「各係数は検証つきの求積で包める有限次元の積分」と書けば足りる。
  - Q3 の剰余 R ＝ 2B h^{n+2}/(n+2)! は正しい。∫_{−h}^{h} |t|^{n+1} dt/(n+1)! ＝ 2h^{n+2}/((n+2)(n+1)!) から確かめた。
