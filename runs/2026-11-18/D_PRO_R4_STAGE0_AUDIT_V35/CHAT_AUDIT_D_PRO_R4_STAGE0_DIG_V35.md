## 結論

1. **段階 0 は PASS と認める。**
   - コードを読み、Simpson の誤差定数を導出と照合した。1 次元では |E| ＝ L⁵|f⁗|/2880 ＝ L·L⁴|j₄|/120 で、正しい。
   - 三つの軸を順に引き継ぐ評価（各軸の誤差を足し合わせる方式）も正しい。正の重みと、ほかの 2 変数を区間にした jet で上界をとっている。
   - 形式除算、正の下界による逆数、優級数の尾も確かめた。いずれも正しい。
   - chat は独自に再計算した。核は V33 で幾何と照合した chat の写し、求積は Gauss–Legendre 6 点、一次の係数は差分による。定数項と一次の係数の計 4 件が、すべて Dig の区間に入った（`chat_stage0_indep.py`）。
2. **段階 1 の NO-GO の原因は、chat が v2 で目安とした閾値 A_j(1) ≤ 1/8 である。** 数学の必然ではない。1/8 は chat が置いた目安で、chat の責任である。
3. **A を大きくしているのは R と τ の方向で、λ の方向はほとんど効かない。** 箱 2 の最悪点（接触方向 h ＝ 1）で、次のようになった（`chat_A_direction_probe.py`）。

   | 外側の半径 | A | 点ごとの尾 |
   |---|---|---|
   | 全方向（箱 2 のまま） | 0.325 | 1.32 |
   | R だけ | 0.131 | 0.021 |
   | t だけ | 0.171 | 0.027 |
   | q（λ）だけ | 0.0008 | 1e−13 |
   | 全方向で半径を 1/2 | 0.153 | 0.029 |
   | 全方向で半径を 1/3 | 0.100 | 0.0035 |

4. **閾値をなくし、収束（A < 1）だけを条件にすると、尾の積分は大きすぎる。** Dig の `majorant()` を点ごとに使った台形則の見積もりでは、5³ の格子で 0.138、9³ の格子で 0.074 だった。値は、接触方向 h → 1 の鋭い山が支配している。予算 0.03 には収まらない見込みである。
5. **したがって、箱 2 は外側で分割する必要がある。** R と τ を 2 つずつに分けると、点ごとの尾は約 1/45 になる。λ は分けなくてよい。この性質は、全域の被覆でも λ の箱を大きくとれることを示唆する。

## 次の工程の候補（Judge の判断）

- (a) **推奨：** 外側を R × τ ＝ 2 × 2 に分ける（λ は分けない。4 箱）。受け入れの規則を「A ≤ 1/4、かつ尾の積分 ≤ 0.03」に変え、走らせる前に固定する。
- (b) 外側を R × τ ＝ 3 × 3 に分ける（9 箱）。閾値 1/8 はそのまま使う（最悪点の A は 0.100）。費用は (a) の約 2 倍である。
- (c) 相関を保つ、より鋭い優級数を先に作る。研究の段階に戻る。
