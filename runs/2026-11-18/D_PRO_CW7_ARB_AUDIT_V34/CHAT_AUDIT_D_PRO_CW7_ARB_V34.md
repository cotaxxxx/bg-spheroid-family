## 結論

- **包含の論理に誤りはない。** 次の点を、コード（`validator.py` の `geom`・`evaluate`）を読んで確かめた。
  - 測度：½ dh dv dw（四分の一の対称、θ ＝ πv/2）は、(1/4π)dΩ dw と一致する。
  - 優級数：A_j ＝ |D_r|/δ₀ の下界、R² の因子 [0, 2r, r²]、尾 ＝ G(1) − Σ_{r≤4} g_r、いずれも正しい。
  - 逆数：正の有理端点 [1/U, 1/L] で作っており、CW6 の停止の原因を正しく直している。
  - 分母の下界：中心のパラメータでの正項表示から作っている。
- **幅が出ない原因は、報告の診断のとおりである。** 原因は二つある。
  - 空間の積分を、セルの値域 × 測度の和（0 次）でしている。V31・V32 で見たのと同じ形の失敗で、点ごとの相殺が保てない。
  - 剰余を受け入れる閾値 A_j(1) ≤ 3/4 が緩い。三つの因子の積で、(1 − 3/4)⁻³ ＝ 64 倍まで膨らみ得る。
  - その結果、測度の 2.8% だけで、剰余の累積が 0.59 に達した。
- **同梱のテストは、chat の環境で再実行して全て PASS だった。** `tests.py`、`local_checks.py`、`extra_checks.py`。
- **この版を長時間走らせることには、報告と同じく反対する。** 必要なのは、空間方向の高次の求積と、セルごとの剰余の予算である。これらを、Codex への R4 指示書の v2 に反映した。

## 指示書 v2 で追加・変更した点

1. **空間の 0 次の積分を禁止する。** 35 係数の符号付きの積分は、高次の求積（誤差を保証したもの）で行う。0 次の和（区間 Riemann 和）は、剰余 B の積分だけに許す。B は非負で、相殺が要らないからである。
2. **セルごとの剰余の予算を、走らせる前に固定する。** A_j(1) の閾値を厳しくし、例えば 1/8 とする。半幅 0.1 の内訳（剰余、係数の求積誤差、箱の上の多項式の値域）を、先に決めておく。
3. **段階を踏む。**
   - 段階 0：一つの空間セルで、35 係数の積分を、chat の高精度参照と照合する。
   - 段階 1：箱 2 の全体。
4. **任意の設計（推奨）：空間の変位も含めた結合 Taylor 模型。** K は、外側の (R, t, q) だけでなく、空間の (h, c ＝ cos²θ, w) についても有理式である。そこで、空間のセル内の変位も、同じ固定分母の優級数 (C10)・(C11) に入れる。多項式の部分は、セルの上の厳密なモーメントで積分する。c についての重み 1/√(c(1−c)) の不完全モーメントは、arcsin と代数関数で閉じる。この方法なら、超越関数の jet を作らずに、相殺を空間方向まで保てる。
5. **CW7 の部品は再利用してよい。** 正の有理端点による逆数と、正項表示による下界である。ただし、再利用であることを明記する。
