## 2. 規則（走らせる前に固定する）

**H の評価：** C21 の細かい較正の規則を使う。base_u ＝ 16、base_v ＝ 32、比 1/2、次数 4、128 bit、python-flint 0.8.0。経路は、箱の位置で決める。

| 経路 | 使う箱 |
|---|---|
| 軸 | τ の上端が 1 の箱 |
| 中心 | R の下端が 0 の箱 |
| 境界カラー | R の上端が 1 の箱（球冠あり） |
| 一般 | それ以外 |

軸の経路（AX）は、C21 で時間の上限に当たった。そこで、軸の経路の 1 箱あたりの時間の上限を、別に固定してよい（例：600 秒）。上限を超えた箱は OPEN として記録し、管の候補に数える。

**初期の分割：** (R, τ) を 16 × 16 の等しい箱に分ける。

**細分の規則（判断は「区間が 0 を含むか」という二値だけで行う）：**

- 区間が 0 を含まない箱は、「決定」とする。符号は記録するだけで、規則には使わない。
- 区間が 0 を含む箱は、正規化した最長の辺で二等分する。同じ長さなら R を先に分ける。
- 辺が 1/256 に達しても 0 を含む箱は、「管の候補」として細分を止める。
- 時間の上限を超えた箱も、管の候補に数える（理由を別に記録する）。

**並列：** 研究用 PC の 12 ワーカーで実行してよい。各箱の時間は、ワーカーの中で測る。順序と結果が再現できるようにすること（箱の ID を固定する）。

**全体の上限：** 実時間 24 時間。上限に達したら、その時点の状態を保存して止める。途中から再開できるようにする。

## 3. 記録するもの

- 箱ごとの記録：ID、範囲、経路、H の区間、半幅、0 を含むか、時間、セル数、peak RSS
- 細分の深さごとの箱の数
- 決定した面積と、管の候補の面積（(R, τ) の測度の厳密な分数で表す。合計は 1）
- 管の候補の箱の数と、その分布（R、τ の範囲）
- 経路ごとの時間の合計と、全体の実時間
- 全域（λ の板の数）へ広げた場合の費用の見積もり。λ ≈ 2 の側は、λ の方向に箱を大きくとれない（V37）ので、板の厚さの仮定を明記する

## 4. あわせて行うこと：特別な経路の較正（被覆の前に行う）

C21 の AX、CE、BD を、細かい較正の規則で計算する。半幅と時間を記録し、§2 の規則を固定する前の参考にする。

## 5. 管の W（この依頼では、時間の測定だけ）

管の候補の箱から、決めておいた規則で 3 箱を選ぶ。例えば、ID の順で最初の 1 箱、中央の 1 箱、最後の 1 箱とする。この 3 箱で、W を R3 の二次の形（V32 で健全性を確かめた方式）で包み、時間と半幅を記録する。管の全体の W は計算しない。
