## 結論

### 1. 新しい式は正しい

chat が導き直して照合した。

| 式 | 内容 |
|---|---|
| γ_ρ | (−ξ_x ＋ kP/D²)/(D√B) |
| γ_ρρ | (−2ξ_x P − k ＋ 3kP²/D²)/(D³√B) |
| ℛ′ | (γℛ − 1)/(1 − γ²) |
| f_ρρ | 4ξ_x ℛγ_ρ − 2k(ℛ′γ_ρ² ＋ ℛγ_ρρ) |
| 軸と中心 | H ＝ ∫₀¹ E_ρρ(sρ, z) ds（E は ρ について偶） |
| 球冠の上界 | \|f_ρ\| ≤ π²/4 ＋ π(1 ＋ λ_max) |

球冠の上界は、次の三つの不等式から出る。

- \|γ_ρ\| ≤ (λ ＋ 1)/D（√B ≥ 1/λ、γ ≤ 1、\|P\| ≤ D による）
- 0 ≤ k ≤ σ ≤ D
- ℛ ≤ π/2

### 2. 独立な参照値（chat の V31 のライブラリ、物理座標 p_z ＝ λz）

照合したのは 10 箱の中心である（`chat_c21_refs.py`）。

- **一致：** 8 箱で、Dig の訂正後の参照値と 1e−11 以下で一致した。
- **差がある 2 箱：** 境界に近い BD（R ＝ 127/128）と STRIP_15（R ＝ 31/32）では、差が 3.4e−5 と 8.9e−6 だった。Dig 自身の 96 点と 160 点の差（4e−5 と 7e−5）と同じ桁なので、どちらの参照値も境界の近くでは精度が足りないためである。producer の誤りを示すものではない。
- **包含：** producer の区間（粗い第 1 回と、細かい較正）は、chat の値をすべて含んでいた。AX は第 1 回が OPEN なので、対象外とした。
- **座標の誤りの訂正：** Dig が訂正した参照の座標の誤り（p_z ＝ z を p_z ＝ λz に）は、Dig 自身の参照にだけ関わる。chat がこれまでに渡した参照値（V31 の W、V36 の H の 5 点）は、最初から p_z ＝ λz で計算しており、影響を受けない。

### 3. 幅と費用（判断材料）

- **第 1 回（8 × 16、比 2）：** 幅が大きすぎて、使えない（半幅 1.3〜187）。
- **細かい較正（16 × 32、比 1/2）：**

  | 箱 | H | 半幅 | 時間 |
  |---|---|---|---|
  | G2 | 0.477 | 0.093 | 28 秒 |
  | G35 | 0.072 | 0.116 | 81 秒 |
  | EQ | −0.082 | 0.046 | 147 秒 |
  | STRIP_08 | 0.071 | 0.19 | 86 秒 |
  | LW（λ の幅 1/4） | 0.425 | 0.94 | 38 秒 |

- **未解決：** AX（軸の近く）は、時間の上限で OPEN になった。CE と BD は、細かい較正がまだない。
- **λ の方向の箱の大きさ：** V35 で、λ の寄与が小さいのは、λ ≈ 5 の箱 2 についてのことだった。λ ≈ 2 では、λ の方向に大きな箱はとれない（LW の λ の寄与は 99、第 1 回）。
- **H の値：** 代表箱の中心での H は、G35 で 0.07、STRIP_08 で 0.07、CE で −0.02 と、小さい所が多い。H の零点の集合は、(R, τ, λ) の中の 2 次元の面である。そのため、W を使う「管」は、薄い所だけでは済まない可能性がある。値は記録として述べただけで、方式の選択には使っていない。

### 4. W の管の B4

二つの変種（軸ごとの深さ、接触座標 u）のどちらも、葉の数の上限（LEAF_LIMIT）で止まった。有理模型による W は、まだ使えない。

ただし、W の管の道具としては、R3 の二次の形がある。健全であることは V32 で確かめ済みで、箱 2 では半幅 0.84、2,729 秒だった。

## 推奨（Judge の判断）

仮の箱数で費用を見積もるのは、ここまでにする。次は、**一つの薄い λ の板の上で、適応的な H の被覆を実際に作る試作**を行う。

- 板：λ ∈ [5 − 1/256, 5]、(R, τ) は全域、細かい較正の規則を使う。
- 実測するもの：
  - 必要な箱の数
  - H の区間が 0 を含んで決まらない部分の面積（管の大きさ）
  - 総時間
- あわせて、AX・CE・BD の細かい較正を行う。

全域の可否は、この実測から判断する。
