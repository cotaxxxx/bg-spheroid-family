# Astra への依頼：針の極限（λ → ∞）から、扁長の停留点の構造を解析的に掴む

## 1. 背景：研究の見方

ユーザー（Judge）の見方は、次のとおりである。

- 扁平の族は、限りなく面（円板）に近づく。扁長の族は、限りなく線（針）に近づく。その中間が立体で、完成形が球である。
- 線の先には届かない 0（赤道面積 → 0）があり、面の先には届かない ∞（赤道面積 → ∞）がある。数学なら、届かない果てでも表せる。

この見方から、λ → ∞ の側で、具体的な式が出てきた。

## 2. 分かっていること

**定義：** 参照体は K_λ ＝ {x² ＋ y² ＋ z²/λ² ≤ 1}、L ＝ diag(1, 1, λ) とする。参照座標 q ＝ L⁻¹p は、単位球の中にある。

```text
E(p) ＝ (1/4π) ∫_{S²} k acos²γ dΩ
k ＝ 1 − q·ξ
γ ＝ k/(D√B)
D² ＝ |ξ − q|² ＋ (λ² − 1)(ξ_z − q_z)²
B ＝ 1 − (1 − λ⁻²)ξ_z²
```

これは、正本の E(p) ＝ ∫α²((x−p)·ν)dA/(3 Vol K) と一致する（V30 で確かめ済み）。

**(a) 中心：** Dig が導出し、chat が独立に検証した。

```text
E_λ(0) ＝ ∫₀¹ arctan²((λ − 1/λ) u√(1−u²)) du      （厳密）
E_λ(0) ＝ π²/4 − π(log λ ＋ 1)/λ ＋ o(1/λ)
```

- 補正の「＋1」は、赤道の帯（視線が壁にまっすぐ当たる所）の寄与と、外側の 1/x の発散が打ち消し合って残るものである。
- 補題：∫₀ᵀ(π²/4 − arctan²x)dx − π log T → π(1 − log 2)。
- 数値では、次の項はおよそ −c(log λ)/λ²（c ≈ 1.2）である。

**(b) 位置への依存（chat の数値の観察。証明ではない）：** q ＝ (ρ, z) で、λ·(π²/4 − E) の log λ についての傾き a(q) は、次の式とよく合う。

```text
a(q) ＝ π √(1 − z²) (1 − z² ＋ ρ²/2)
```

- 4 点で推測し、残りの 3 点で予言を確かめた。差は 4e−3 以下で、有限の λ の影響と整合する。
- 1 − z² ＝ χ（水平断面積の比）を使えば、a ＝ π√χ (χ ＋ ρ²/2) と書ける。点を通る水平の断面の円だけで決まる形である。
- 主要な次数では、次のことが従う。
  - H ＝ E_ρ/ρ ≈ −(π log λ/λ)√(1 − z²) < 0
  - 軸の上で g > 0
  - 中心が唯一の停留点で、鞍点である
- 場所：`cotaxxxx/bg-spheroid-family`、branch `evidence/c-gap2-freeze-20261115`、commit `34ae80e`、`runs/2026-11-18/D_PRO_NEEDLE_LIMIT_NOTE/`（ノート、スクリプト、ログ）。

**(c) 球の側：** あなたの以前の報告 (C19)・(C20) で、λ → 1 での W/log λ の極限 A(R) が出ている。これは chat が検証した。

**(d) 窓の中の今の主路線：** 条件 (C21)（全域で H の符号を区間計算で調べ、W は H ≈ 0 の管でだけ使う）である。区間計算は動いているが、全域で約 1 か月の規模になる見込みである。λ ≈ 5 の重い板を、いま研究用 PC で計算している。

## 3. 考えてほしいこと（制限なし）

1. **展開の導出：** E_λ(q) ＝ π²/4 − (π/λ)[a(q) log λ ＋ b(q)] ＋ R_λ(q) を、元の定義から導くこと。
   - a(q) が上の式になることを証明するか、反証すること。
   - b(q) を求めること。
   - 剰余 R_λ(q) の、明示的な上界を与えること。
2. **微分：** 同じ展開が、q について微分しても成り立つか（∂_ρ、∂_z、必要なら二階まで）。H ＝ E_ρ/ρ と g、そして ρ → 0 と z → ±1 での扱いを含めること。
3. **一様性と境界層：** |q| → 1 の近く（接触点、とくに極の先端）で展開がどう壊れ、どう補えるか。極と境界が重なる隅は、区間計算でも専用の経路が必要になっている（R63_T63）。
4. **有限の λ への接続：** 剰余の上界を明示的にして、「λ ≥ Λ₀ なら停留点は中心だけ」と言える Λ₀ を与えること。Λ₀ が 5 以下になる道があるか、ないならどこまで下げられるかを、数字で示すこと。窓 [2, 5] の区間計算と組み合わせて答えを閉じるには、Λ₀ がどこまで必要かを書くこと。
5. **面の極限（λ → 0）：** 同じ考え方で、扁平の側の展開が作れるか。扁平は確定済みなので、検算として使える。余力があればでよい。
6. **球との関係：** (C19) の A(R)（λ → 1）と、針の極限の a(q)・b(q) が、族全体の一つの像（面 → 球 → 線）として理解できるか。できる範囲でよい。
