## 2. 位置への依存（数値の観察）

参照座標 q ＝ (ρ, z) をとる（物理座標は p ＝ (ρ, λz)）。λ·(π²/4 − E) の log λ についての傾き a(q) を、λ ＝ 10³ から 10⁴ への差から求めた。

候補の式は、次のとおりである。最初の 4 点から推測し、残りの 3 点で予言を確かめた。

```text
a(q) ＝ π √(1 − z²) (1 − z² ＋ ρ²/2)
```

| q | 測った a | 候補の式 |
|---|---|---|
| (0, 0) | 3.1451 | 3.1416 |
| (0.5, 0) | 3.5377 | 3.5343 |
| (0.8, 0) | 4.1501 | 4.1469 |
| (0, 0.5) | 2.0443 | 2.0405 |
| (0.5, 0.5)（予言） | 2.3811 | 2.3806 |
| (0.3, 0.7)（予言） | 1.2456 | 1.2452 |
| (0, 0.8)（予言） | 0.6791 | 0.6786 |

差はどの点でも約 4e−3 以下で、有限の λ の影響の大きさと整合する。

**読み方：**

- χ ＝ 1 − z² は、点の高さでの水平断面積の比である（Astra の χ）。式は a ＝ π√χ (χ ＋ ρ²/2) と書ける。点を通る水平の断面の円（半径 √χ）と、その中での点の位置 ρ だけで決まっている。
- 主要な次数では、E ≈ π²/4 − (π log λ/λ)·a(q) となる。このとき、次のことが従う。
  - H ＝ E_ρ/ρ ≈ −(π log λ/λ)√(1 − z²) < 0：内部の全体で負で、H ＝ 0 の面がない。
  - ∂_z E > 0（z > 0）：軸の上で g > 0。
  - 中心は、ρ の方向に極大、z の方向に極小の鞍点で、唯一の停留点である（λ ≥ a_c で中心だけ、という主張と整合する）。

## 3. 限界

- a(q) の式は、数値の当てはめと予言の一致にすぎない。導出も剰余の評価もない。
- O(1/λ) の項 b(q) は、まだ求めていない。λ ≈ 5 では、log λ/λ と 1/λ の差が小さいので、b(q) が効く。主要な次数だけでは、窓 [2, 5] には使えない。
- 境界（|q| → 1）の近くで展開が一様に成り立つかは、未確認である。
