## 0. 記号

形は L = diag(1, s, st)（s ≥ 1、t ≥ 1。半軸は ℓ₁ = 1 ≤ ℓ₂ = s ≤ ℓ₃ = st）。q は参照球（単位球）の点。E_i、E_ij は q についての微分。

| 記号 | 定義 |
|---|---|
| h_i | E_ii(0)。中心の固有値 |
| κ_i(r) | E_i(r e_i)/r。軸 e_i の上の勾配を r で割ったもの。κ_i(0) = h_i |
| b_i | κ_i(1) = E_i(e_i)。極 e_i での勾配のトレース |
| W₃ | E₃/q₃（q₃ = 0 では E_33） |
| T | せん断のテンソル ⟨2kα cot α (u⊗u − ν⊗ν)⟩ |
| C₁₂ | T₁₂/(q₁q₂)（滑らかに延長したもの） |

恒等式（報告の命題 3）：E₂/q₂ − E₁/q₁ = (s − 1/s)·C₁₂。とくに中心で h₂ − h₁ = (s − 1/s)·C₁₂(0)。

4 本の零曲線は Z_i = {h_i = 0}、∂_i = {b_i = 0}（i = 1, 2）。

## 1. 条件の一覧

### 1.1 報告の命題 4（条件付きの構造定理）が仮定する 3 つ

| 名前 | 条件 | 場所 |
|---|---|---|
| (H3) | W₃ = E₃/q₃ > 0 | 閉球の q₃ ≠ 0 の部分（境界ではトレース）。開いた円板 {q₃ = 0, \|q\| < 1} では E_33 > 0 |
| (H12) | C₁₂ = T₁₂/(q₁q₂) > 0。同じことだが (E₂/q₂ − E₁/q₁)/(s − 1/s) > 0 | 閉じた円板 {q₃ = 0, \|q\| ≤ 1} の上**だけ** |
| (HB) | κ_i′(r) < 0（i = 1, 2） | 軸の上、0 < r < 1。r = 1 ではトレースの値に連続につながる |

結論（形 (s, t) を 1 つ固定するごとに）：停留点は、中心と、h_i > 0 ≥ b_i を満たす i ∈ {1, 2} についての軸の上の対 ±r_i e_i だけである。

### 1.2 「出入り」を言うのに要るが、命題 4 には入っていない条件

命題 4 は形を固定したときの主張である。曲線を横切るときに対が実際に現れる・消えると言うには、次が要る。

| 名前 | 条件 | 記録の有無 |
|---|---|---|
| (T-Z) | Z_i の上で h_i の (s, t) についての勾配が 0 でない（h_i が曲線の両側で符号を変える） | 一般には記録なし。角 (1, λ_c^pro) の近くだけ、報告の命題 6 に傾きの数値がある |
| (T-∂) | ∂_i の上で b_i の (s, t) についての勾配が 0 でない | 記録なし |

数値の地図では、曲線は符号の変わり目として追跡し（Run B、`out/runB_curves.json`）、両側の停留点の数は格子の census（Run A、`out/runA_census.jsonl`）で数えた。勾配が 0 でないことを独立の量として記録してはいない。

## 2. それぞれの条件が保証すること

| 条件 | 保証すること |
|---|---|
| (H3) | 面 q₃ = 0 の外に停留点がない（一般の位置、e₃ 軸の上を含む）。すべての停留点で E_33 > 0（e₃ の方向に退化しない）。h₃ > 0 |
| (H12) | 面 q₃ = 0 の中で、2 本の軸の外（q₁q₂ ≠ 0）に停留点がない。つまり分岐は軸の方向でだけ起きる。軸の上の停留点で、面内の横の方向の符号が決まる：e₁ の対で E_22 = (s − 1/s)C₁₂ > 0、e₂ の対で E_11 = −(s − 1/s)C₁₂ < 0。これが指数 1 と指数 2 の区別を与える。中心で h₁ < h₂（Z₁ の上で h₂ > 0、Z₂ の上で h₁ < 0。0 になる固有値は 1 つだけ） |
| (HB) | 軸の上の対は高々 1 組。対があるのは h_i > 0 ≥ b_i のとき、そのときに限る。対の位置 r_i は κ_i の唯一の零点。軸の方向に退化しない（E_ii = r κ_i′ < 0）。r_i = 1（境界に着く）のは b_i = 0 のときに限る |
| (HB) を r → 0 まで見たもの | κ_i′(r)/r の r → 0 の極限は κ_i″(0) で、中心のピッチフォークの高次の係数にあたる。これが負であれば、h_i が 0 を横切るときの分岐は退化しない。地図では (rE_ii − E_i)/r³ = κ_i′(r)/r を調べている（§3） |
| (T-Z)、(T-∂) | 曲線を横切るときに h_i、b_i が実際に符号を変える（横断的である）こと |

まとめると、(H3)・(H12)・(HB) が成り立つ形の範囲では、停留点の地図は 4 つの数 h₁、h₂、b₁、b₂ の符号で読める。零曲線の配置を確定しただけでは、この読み方は出てこない。

### 3.2 破れの記録

**(a) (H12) が中心で破れる（h₁ = h₂ の逆転の曲線）。**

h₂ − h₁ = (s − 1/s)C₁₂(0) が 0 になる曲線を追跡した。この曲線より t が大きい側で C₁₂(0) < 0 である。

| s | 6 | 8 | 12 | 16 | 24 | 32 |
|---|---|---|---|---|---|---|
| 逆転の t | 35.24 | 28.71 | 22.16 | 18.83 | 15.38 | 13.55 |

- ファイル：`out/runE_reversal.json`。報告の §2.7 と、命題 4 の注意。

- 針状の極限の発見的な式からは、どの s > 1 でも t を十分大きくすれば逆転すると読める（報告 §2.7）。証明ではない。

## 4. 候補 B の領域 R への換算

### 4.1 換算（前提つき）

候補 B の導出原本は読んでいない。依頼文の「x = 1 が中間軸、y ≤ 1 ≤ z」から、半軸が (y, 1, z) で、y が最短、z が最長であると読んだ。E は半軸について 0 次の斉次なので、私の (1, s, st) を s で割ると (1/s, 1, t) になる。

> y = 1/s、z = t　（s = 1/y、t = z）

R = [1/4, 1] × [1, 7] は、私の座標で **1 ≤ s ≤ 4、1 ≤ t ≤ 7** である。候補 B の y、z が半軸の比そのものでない場合（二乗、体積で正規化したもの など）は、この換算は当てはまらない。

### 4.2 破れの場所は R の中か外か

| 記録 | 私の座標 (s, t) | 候補 B の座標 (y, z) | R との関係 |
|---|---|---|---|
| (a) (H12) の中心での破れ | s = 6〜32、t ≥ 13.55〜35.24 | y = 0.031〜0.167、z ≥ 13.55 | **外**。y < 1/4 かつ z > 7 |
| (a) の s < 6 の部分 | 記録なし | y > 1/6 | 記録なし。逆転の t は s が小さいほど大きい（s = 6 で 35.2）ので、R（z ≤ 7）の中に入るとは考えにくいが、追跡していない |
| (b) (1.25, 32) | (1.25, 32) | (0.8, 32) | **外**。z > 7 |
| (c) 面の外の順序の破れ | 19 形 | — | **12 形が R の中**：(s, t) = (1.2, 6.5)、(1.5, 6.5)、(2, 5)、(2, 6.5)、(2.6, 5)、(2.6, 6.5)、(3.3, 4)、(3.3, 5)、(3.3, 6.5)、(4, 4)、(4, 5)、(4, 6.5)。残り 7 形は t = 8 で R の外 |

### 4.3 R の中での 3 条件の記録

- 私の窓（1 ≤ s ≤ 4、1 ≤ t ≤ 8）は R を含む。§3.1 の確認はすべて R を覆っている。
- R の中（t ≤ 7）に限ると、(H12) の最小は、`probe_plane12.json` の 72 形で 0.032（(s, t) = (4, 6.5)、つまり (y, z) = (0.25, 6.5)）、`probe_shear_sign.json` の 25 形で 0.048（(4, 4.7)）である。R の角 (y, z) = (1/4, 7) に向かって余裕が小さくなる。
- Codex の主矩形 [1, 3.2] × [1, 6]（(y, z) では [0.3125, 1] × [1, 6]）は R より小さい。R のうち y < 0.3125 または z > 6 の帯については、私の側にあるのは、この非区間の粗い格子の記録だけである。

### 4.4 読み方

- 命題 4 が使う 3 条件のうち、破れが記録されているのは (H12) だけで、記録された場所は R の外である。
- R の中では、3 条件とも、調べた形では成り立っていた。ただし、非区間で、形は 30〜80 個の粗い格子であり、(T-Z) と (T-∂) は調べていない。
- 候補 B の証明が、面 q₃ = 0 の上の条件ではなく、球の全体での順序（E₂/q₂ − E₁/q₁ > 0 を面の外でも）を使っているなら、それは R の中で数値的に破れている（(c)）。どちらを使っているかは、候補 B の原本で確かめる必要がある。
