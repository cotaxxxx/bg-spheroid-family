## 証明の構造（このスクリプトが確かめること）

chat は Astra の証明書を使わない。V3 設計書（SHA `e6660d52…`）と μ16 の分割（τ・s・λ・t は V2 のまま、μ_j ＝ −1 ＋ j/8）だけから、枝ごとに次を行う。

1. chat 独自の区間包囲（`ftq_v2_chat.py` の `enclosure`、32 bit の外向き丸めの根）で、(t, γ, k, n) の箱と S・Δ²・Y²・w² の区間を得る。
2. 設計書 §5 の規則で8本の制約 Q₁〜Q₈ の係数を作る。
3. 対象 P ＝ γF/(KA²) の分子・分母を、多重次数 (4,4,6,2) の Bernstein 係数に厳密な有理数で直す。分母の係数がすべて正であることを確かめる。
4. 浮動小数の LP（HiGHS）は乗数の候補を探すためだけに使う。候補を有理数に直し、乗数を非負に切り、残差 b ＝ b⁰ − z·d − H·a と利得 z を厳密な有理数で作り直す。b ≥ 0、z ≥ 0、a ≥ 0 と、恒等式 N − ℓD ＝ Σ bβ ＋ Σ σQ が係数ごとに一致することを assert で確かめる。
5. 枝ごとの ℓ は、LP の最適値ではなく、厳密に検査した**実行可能な証明書**の値である。したがって ℓ_chat ≤ ℓ_Astra になる。
6. 対の寄与を (ℓ₊ ＋ ℓ₋)/192（s の下の区画）と /96（上の区画）で集め、16 区画の和 S_ia と、その最小 m₀ を厳密な分数で出す。

この証明は Astra の本走の束（ChatGPT の Library に不完全な形で残るもの）に依存しない。
