1．結論

面積比の着想は有望である。ただし、効くのは変数名の変更ではなく、反射対を合成した後に微分し、その和と積を使って有理核へ変形する部分である。

本書では、角度端点の平方根・差商・4階Taylor剰余を含まない、元のWと厳密に同じ積分表示を導く。さらに、反射対の積を P²−J として引き算せず、正の項の和の積として評価できる。

主成果を先に示す。記号は§2で定義するが、Pは反射した二つのCBの平均、Δはその積であり、プライムはR、λ、球面座標を固定したt微分である。補助積分変数w∈[0,1]と

[
a_0=k^2/\sigma^2,\quad A=a_0(1-w^2),
\quad S=A^2+2Aw^2P+w^4\Delta
]

を用いると、R>0で

[
\boxed{
W=\frac1{4\pi}\int_{S^2}\int_0^1
\frac{2ka_0}{R^2},
\frac{\frac A2\Delta'+w^2(P\Delta'-\Delta P')}{\Delta S}
,dw,d\Omega.}
\tag{R4-1}
]

この式のt依存は有理式であり、(\sqrt{t(1-t)})、1/t、1/(1−t)を含まない。P、Δ、Sの正値は幾何から保証でき、PとΔにも正項表示がある。ただし分子は点ごとには正でない。積分後のW>0は未証明である。

実装順の推奨は次のとおり。

箱2では直接W（方法B）を最初に比較する。 箱全体が角度端点から離れており、赤道まで伸ばした4階微分包囲を必要としない。変更量が小さく、旧端点剰余の影響を切り分けられる。

新しい対称多項式核（方法C）を、角度端点を含む評価の本命候補とする。 箱2でも同じ核を比較する。補助積分wの費用と誤差が増えるため、実測前に速さや半幅0.3の達成を約束しない。

中心R=0は別処理とする。新核のR⁻²をそのまま使わない。§4.3に中心用の厳密な積分剰余表示も示すが、実用幅は未検証である。

2．独立導出：元のEから新しいWの核まで

2.1 体積保存正規化と測度

(L=\operatorname{diag}(1,1,\lambda))、(K=L B^3) とし、まず赤道半径1の参照楕円体で計算する。体積保存族はaK、(a=\lambda^{-1/3}) である。旧扁長資料の回転軸yを、本書ではzとする（y↔z）。

境界点x=Lξ、基点p=Lq、|ξ|=1とすると、法線付き面積の変換は

[
\nu,dA=\det L,L^{-T}\xi,d\Omega,
\qquad ((x-p)\cdot\nu)dA=\lambda(1-q\cdot\xi)d\Omega.
]

3Vol(K)=4πλであるから、原定義は正確に

[
E(p)=\frac1{4\pi}\int_{S^2}kG(\gamma)d\Omega,
\quad k=1-q\cdot\xi,
\quad G(\gamma)=\arccos^2\gamma,
]
[
D^2=(\xi-q)^TL^2(\xi-q),\quad
B=\xi^TL^{-2}\xi,\quad\gamma=\frac{k}{D\sqrt B}
\tag{R4-2}
]

となる。これはR0式(3)と同じ正規化であるが、ここでは原定義から再導出した。[S1 §3.1、式(3)]

相似不変性はEの値を保つが、座標微分の数値まで保つわけではない。物理座標で定義した (H_{\rm phys},V_{\rm phys},W_{\rm phys}) と参照座標の量の関係は

[
W_{\rm phys}=a^{-2}W=\lambda^{2/3}W.
\tag{R4-3}
]

以後のWは参照座標での (\lambda^2V-H) とする。符号は物理座標と一致する。

2.2 面積比の連鎖律

[
\mathscr E(R,\beta;\lambda)=E(R\cos\beta,0,\lambda R\sin\beta),
\quad t=\sin^2\beta,
\quad\chi=1-R^2t.
]

物理座標の高さはz_phys=aλRsinβ、極半径c=aλなので、水平断面積の比も正確にχである。R、λを固定し、0<β<π/2では

[
\mathscr E_\beta=-R\sin\beta E_\rho+\lambda R\cos\beta E_z
=R^2\sin\beta\cos\beta(\lambda^2V-H).
]

したがってR>0で

[
\boxed{W=\frac{2}{R^2}\mathscr E_t=-2\mathscr E_\chi.}
\tag{R4-4}
]

(\mathscr E_\chi) はR、λを固定した曲線上の微分であり、ρを固定した鉛直微分ではない。物理Wを使うなら右辺にa⁻²が必要である。R=0ではχ=1に潰れるため、χによる座標微分を直接定義しない。

2.3 共回転と反射対

Oβをe_xを(cosβ,0,sinβ)へ送る回転とし、ξ=Oβηと置く。η=(h,η_y,v)、|η|=1である。以下はR<1、またはR=1でη≠e_xの点について定義する。

[
\Sigma=\sigma^2=(1-R)^2+2R(1-h),\quad k=1-Rh,
\quad a=\frac{h-R}{\sigma},\quad b=\frac v\sigma,
\quad a_0=\frac{k^2}{\Sigma}.
\tag{R4-5}
]

ここだけのaはm₀のx成分であり、§2.1の相似係数とは別である。以後、相似係数は使用しない。d=λ²−1、e=d/λ²とする。

[
C=1+d m_z^2,\quad B=1-e\xi_z^2,\quad
m_z=\sqrt t,a+\sqrt{1-t},b,
\quad\xi_z=\sqrt t,h+\sqrt{1-t},v.
]

η_z=vを−vへ反射するとbも反転する。従って

[
C_0=1+d[(1-t)b^2+ta^2],\quad
B_0=1-e[(1-t)v^2+th^2],
]
[
P=C_0B_0-4de,t(1-t)abhv,\quad
D_0=dabB_0-ehvC_0,
]
[
P_\pm=P\pm2\sqrt{t(1-t)}D_0,
\quad J=4t(1-t)D_0^2,\quad
\Delta=P_+P_-=P^2-J.
\tag{R4-6}
]

反射は測度とkを保つため、(\phi(X)=G(\sqrt{a_0/X})) として

[
\mathscr E=\frac1{4\pi}\int k\Psi(P,J)d\Omega,
\quad \Psi(P,J)=\frac{\phi(P+\sqrt J)+\phi(P-\sqrt J)}2.
\tag{R4-7}
]

これはR0 §4.4の構造を独立に展開して確認したものである。P±の名前はD₀の符号によって交換されるが、平均と積は変わらない。

2.4 偶数差商の正確な延長

J>0、P−√J>0で、φが当該区間でC²なら

[
\Psi_P=\frac{\phi'(P+\sqrt J)+\phi'(P-\sqrt J)}2,
]
[
\Psi_J=\frac{\phi'(P+\sqrt J)-\phi'(P-\sqrt J)}{4\sqrt J}
=\frac14\int_{-1}^1\phi''(P+u\sqrt J)du.
\tag{R4-8}
]

最後の等式は基本定理と変数置換から従う。J↓0では

[
\Psi_P(P,0)=\phi'(P),\qquad \Psi_J(P,0)=\tfrac12\phi''(P).
]

幾何学的な真値はP±≥a₀>0を満たす。φはX=a₀でも滑らかであり、下記の式がそれを直接示す。反射平均のJ微分の符号は負だが、(\mathscr E_t) には (\Psi_P P'+\Psi_JJ') の両方がある。

2.5 φ′を有理積分にする

x=X/a₀−1≥0と置けば、φ(X)=atan²√xなので

[
\phi'(X)=\frac1X\frac{\arctan\sqrt x}{\sqrt x}
=\int_0^1\frac{a_0}{X{a_0(1-w^2)+w^2X}}dw.
\tag{R4-9}
]

x=0で商を1へ延長する。最後の等式は (\arctan y/y=\int_0^1(1+y^2w^2)^{-1}dw) による。

固定wについてr_w(X)=a₀/[X(A+w²X)]、A=a₀(1−w²)と置くと

[
r_w'(X)=-\frac{a_0(A+2w^2X)}{X^2(A+w^2X)^2}<0.
]

よってφ′>0、φ″<0を再び得る。これはR0式(12)を再利用するだけでなく、区間演算に適した別の証明である。

L_w=A+w²P、S=L_w²−w⁴Jとすると、分母を通分するだけで

[
\Psi_P=\int_0^1\frac{a_0(PL_w+w^2J)}{\Delta S}dw,
\quad
\Psi_J=-\int_0^1\frac{a_0(L_w+w^2P)}{2\Delta S}dw.
\tag{R4-10}
]

例えば後者の分子は、r_w(P+√J)−r_w(P−√J)を通分すると−2√J·a₀(L_w+w²P)となり、√Jが約分される。J=0でも右辺が有効である。

二つの寄与を別々に包んで最後に足すのではなく、先に共通分子にまとめる。

[
N=(PL_w+w^2J)P'-\tfrac12(L_w+w^2P)J'
=\tfrac A2\Delta'+w^2(P\Delta'-\Delta P').
\tag{R4-11}
]

またS=A²+2Aw²P+w⁴Δである。(R4-4)、(R4-7)、(R4-10)を合わせると、主式(R4-1)を得る。補助積分wを導入する代わりに、J自体を本番の評価式から消せる。

3．相殺の解析と、正項で計算できる分母

3.1 PとΔも減算を避けられる

y₂=η_y²、(B_*=\lambda^{-2}+ey_2)、(U=(1-t)h^2+tv^2) とする。次は全て非負項の和である。

[
\boxed{
P=B_*C_0+eU+de\left[
t(1-t)(ah-bv)^2+{(1-t)bh-tav}^2\right].}
\tag{R4-12}
]

さらに

[
D_C=1+2d[(1-t)b^2+ta^2]+d^2[(1-t)b^2-ta^2]^2,
]
[
D_B=B_^2+2B_eU+e^2[(1-t)h^2-tv^2]^2,
\qquad\boxed{\Delta=D_CD_B.}
\tag{R4-13}
]

証明。 B=B_+eξ_x²である。CB=B_C+eξ_x²+de(m_zξ_x)²と分け、反射平均を取る。(m_z\xi_x=\sqrt{t(1-t)}(ah-bv)+(1-t)bh-tav) の前項は反射で不変、後項は符号反転するため交差項が消え、(R4-12)となる。C₊C₋はC₀²−4d²t(1−t)a²b²を展開し、平方項を残すとD_Cになる。B₊B₋にもB_*+eξ_x²の形で同じ操作を行えばD_Bとなる。P₊P₋=(C₊C₋)(B₊B₋)より(R4-13)。□

この表示は P²−J の近い値同士の減算を不要にする。Pには(R4-12)、Δには(R4-13)、Sには正項和を使い、Nだけを符号付きの共通多項式として扱う。

σの平方根も不要である。例えば

[
a^2=(h-R)^2/\Sigma,\quad b^2=v^2/\Sigma,
]
[
(ah-bv)^2={h(h-R)-v^2}^2/\Sigma,
\quad {(1-t)bh-tav}^2
=v^2{(1-t)h-t(h-R)}^2/\Sigma.
\tag{R4-14}
]

したがって球面座標が与えられれば、(R4-1)全体はR,t,λ,wの有理式である。tの平方根を分離して包む必要がない。

3.3 点ごとの正値化にはならない：解析的な負の核

λ>1、0<R<1、η=e_xではa=h=1、b=v=0、a₀=1である。このとき

[
P=1+de,t(1-t),\quad J=0,\quad
\partial_t{k\Psi}=k\phi'(P)de(1-2t).
]

t>1/2でこれは負である。内部R<1では密度は連続なので、その周囲の正の面積を持つ小領域でも負になる。従って「新核が各点で正」という証明はできない。これはWの積分値が負であるという反例ではない。

3.4 低次元化について得られた範囲

反射後のP、Δはv²とη_y²だけに依存する。固定hでv²=(1−h²)cos²θとすれば、角度平均を

[
\frac1{2\pi}\int_0^{2\pi}F(\cos^2\theta)d\theta
=\frac1\pi\int_0^1\frac{F(z)}{\sqrt{z(1-z)}}dz
\tag{R4-15}
]

へ変えられる。これは厳密な重み付き一変数平均だが、全体はh,z,wの積分であり、元の二変数求積より次元が減ったわけではない。wを共通有理モーメントとして解析的に消す、またはz平均後の符号不等式を証明することが次の課題である。今回、積分後の正値性を保証する一次元不等式までは得ていない。

4．端点と中心

4.1 t=0、1

J=0でもJ′は一般には0でない。

[
J'(0)=4D_0(0)^2,\quad J'(1)=-4D_0(1)^2.
]

従って

[
\partial_t\Psi\big|_{t=0,1}=\phi'(P)P'+\tfrac12\phi''(P)J'.
\tag{R4-16}
]

J=0を理由に第2項を捨てると誤った端点核になる。(R4-1)はこの項を自動的に含む。分母が正であるため、そのままt=0、1を代入できる。連鎖律から

[
W(R,0)=\mathscr E_{\beta\beta}(R,0)/R^2,
\quad W(R,\pi/2)=-\mathscr E_{\beta\beta}(R,\pi/2)/R^2
]

とも一致する。区間が端点を含んでも、未定義な差商を計算してから極限を取る必要はない。

4.2 R→1、接触球冠

q_c=1−h≥κ>0の補集合ではΣ≥2Rκ。R=1を含む箱でも通常の有理核として微分・積分できる。球冠内では高階のR微分を包もうとせず、元の角度二階微分の支配を使う。

R0式(5)〜(8)から、(\ell=\lambda-\lambda^{-1})、(C_\lambda=2(\lambda^2-1)+2\ell^2) として

[
|T|\le\ell,\quad |T_\beta|\le2(\lambda^2-1)+\ell^2,
\quad |f_{\beta\beta}|\le\pi C_\lambda k.
\tag{R4-17}
]

各項の証明は、例えば (d|m_xm_z|/(1+dm_z^2)\le d/(2\lambda)) を平方完成で示し、ℛ≤π/2、0<ℛ+γℛ′≤ℛを使うものである。[S1 §4.1、式(13)]

反射対の密度も同じ上界を持ち、β=0、π/2で一階微分が0になる。基本定理と
(\min(\beta,\pi/2-\beta)/(\sin\beta\cos\beta)\le\pi/2)
により、w積分後の新しいW密度は絶対値が (\pi^2C_\lambda k/(2R^2)) 以下である。

従って支配収束で角度微分と球面積分を交換でき、R=1への延長も成立する。接触一点では密度を0へ延長できる。ただし、wをまだ積分していない三変数核が、接触点で一様有界だとは主張しない。 a₀→0でw方向の急変が生じうる。

球冠の寄与には従来と同じ

[
|W_{\rm cap}|\le\frac{1176}{5R^2}
\left((1-R)\kappa+\frac{R\kappa^2}2\right)
\tag{R4-18}
]

を使える。証明は ((4\pi)^{-1}\int_{q_c<\kappa}k,d\Omega
={(1-R)\kappa+R\kappa^2/2}/2) と、π²<10、Cλ≤2352/25による。外箱ではR下端・上端を使って一様上界を取る。補集合の平均値評価の後に一度だけ加える。新旧核で同じ球冠を二重に引かない。

4.3 R=0と中心近傍

反射と回転対称性により内部のEは滑らかで、

[
\mathscr E=E(0)+\frac{R^2}{2}{Q(1-t)+\lambda^2Q_z t}+O(R^4),
\quad W(0)=\lambda^2Q_z-Q.
\tag{R4-19}
]

ここでQ=E_xx(0)、Q_z=E_zz(0)である。R=0で共回転密度はなおtに依存し、その積分だけがtに依存しなくなる。従って(R4-1)の分子が各球面点でR²を因子に持つとはいえない。

中心用の別の厳密表示は構成できる。f_tの新しい密度を

[
q(R,t,\lambda;\eta,w)=\frac{ka_0N}{\Delta S},
\quad I(R)=\frac1{4\pi}\int!\int q,dw,d\Omega=\mathscr E_t(R,t;\lambda)
]

とする。固定R_*<1の範囲でqは必要次数だけ滑らかである。E(-p)=E(p)よりIはRの偶関数、またI(0)=0だから、Taylorの積分剰余により

[
\boxed{
W(R,t;\lambda)=\frac2{4\pi}\int_{S^2}\int_0^1\int_0^1
(1-v_),\partial_R^2q(v_R,t,\lambda;\eta,w)
,dv_*,dw,d\Omega.}
\tag{R4-20}
]

これはR=0にも有効であり、R⁻²除算もTaylor打切りもない。証明ではI(0)=I′(0)=0を積分後の恒等式として用いている。各密度の定数・一次項が0だとは仮定しない。

ただし、追加のv_*積分とR二階微分が必要になる。実用幅・計算費用はOPENであり、既存の中心Q方式を置換する勧告ではない。R=0そのものには(R4-19)を使う方が簡潔である。

5．厳密区間包囲の設計

5.1 幾何学的な正の下界

単位ベクトルから (1\le C_\pm\le\lambda^2)、(\lambda^{-2}\le B_\pm\le1)。従って

[
P\ge\lambda^{-2},\quad \Delta\ge\lambda^{-4},\quad
0<a_0\le1.
\tag{R4-21}
]

補集合q_c≥κには、さらに有用な下界がある。

[
\boxed{a_0\ge q_c/2\ge\kappa/2.}
\tag{R4-22}
]

証明。 q=q_c∈[0,2]について

[
k^2-\frac q2\Sigma
=(1-R)\left[(1-R)(1-q/2)+Rq(2-q)\right]\ge0.
]

Σ>0で割ればよい。上界a₀≤1はk=(η−Re_x)·ηとCauchy–Schwarzによる。□

[
S=(A+w^2P_+)(A+w^2P_-)
\ge{a_0(1-w^2)+w^2\lambda^{-2}}^2.
]

よってλ≤5、球冠外では

[
\Delta\ge1/625,\qquad
S\ge\min(\kappa/2,1/25)^2>0.
\tag{R4-23}
]

球冠なしでR≤R_<1なら、Σ≥(1−R_)²、a₀≥(1−R_)²/(1+R_)²を代わりに使える。これらは粗くても厳密な逆数の安全域になる。

Arbの球による積が0を跨いだ場合も、真のΔやSの正値が失われたわけではない。正項表示と証明済み下端を用いて定数係数の範囲を交差させ、正の逆数を端点で囲む。任意のepsilonを足したり、clippingの微分を導関数として使ったりしない。矛盾する交差が出たら停止する。

5.2 必要な微分・上界をどう作るか

球面座標には既存の (u=\tan(\psi/4)) を使い、

[
h=1-\frac{8u^2}{(1+u^2)^2},\quad
v=\frac{4u(1-u^2)}{(1+u^2)^2}\cos\theta,
\quad\eta_y=\frac{4u(1-u^2)}{(1+u^2)^2}\sin\theta
]

とする。y₂を1−h²−v²という広い減算だけから作らず、上記の平方表示を使う。単位球恒等式はP、Δの導出と同時に保持する。

最小実装では、三つの積分変数u、θ、wについて逐次中点則と二階微分剰余を用いればよい。全セルでの (|\partial_{jj}F|\le M_j) が得られれば、幅h_jの直方体セルの中点則誤差は

[
\left|\int_C F-|C|F(c)\right|
\le |C|\sum_j h_j^2M_j/24.
\tag{R4-24}
]

証明は一変数中点則を順次適用し、残りの変数についても全セルの上界を使う。混合項の符号を仮定しない。実用上はR3の6次逐次求積を三変数へ拡張できるが、全セルで包んだ最高次導関数と正しい中心モーメントを必須にする。

必要な上界は新しい有理核を微分してから区間評価する。多重添字αのjetでF=U/Dを扱うなら、係数は

[
F_0=U_0/D_0,\qquad
F_\alpha=\frac{U_\alpha-\sum_{0<\gamma\le\alpha}D_\gamma F_{\alpha-\gamma}}{D_0}.
\tag{R4-25}
]

導関数はα!倍である。正のD₀下端は(R4-21)〜(R4-23)から得る。これにより必要次数の計算可能な厳密上界を構成できる。鋭い数値上界が既に得られた、という意味ではない。平方・逆数でR2の正値評価順序を保持する。

点積分には二階または六階の空間微分、外箱平均値補正にはR,t,λの一階微分が必要である。外箱の導関数をセル値域積分で囲む最小版なら、さらに高い混合求積微分は不要である。導関数積分も高次求積にするなら、その外側一階と各求積方向の必要次数を合わせたjetを使う。中心表示(R4-20)は追加でR二階が必要になる。

5.3 外箱と球冠

固定した補集合上の積分Iに対し、箱(\mathcal B)、中心p₀を用いて

[
I(\mathcal B)\subset I(p_0)+\sum_i [\partial_i I](\mathcal B)(\mathcal B_i-p_{0i}).
\tag{R4-26}
]

これは基本定理による。補正は一般には箱幅の一次である。中心点は点求積、導関数は箱全体の核から包む。R微分ではk、a₀、Σ、A、P、Δの依存を全て微分する。t微分の式でa₀が固定だったことを、R微分に誤って持ち込まない。

球冠の切り方は箱全体で固定し、微分は補集合の中だけで行い、最後に(R4-18)を一度加える。面積比χを独立の箱としてR,tと同時に渡さない。χ=1−R²tは従属量である。

7．失敗可能性と別の排除方式

面積比だけでは改善しない。 βをtに置き換えてからsqrt(t)を生の区間で評価すれば、むしろ端点微分が悪化する。反射平均と対称多項式まで実装する必要がある。

分母の正項化だけでも十分ではない。 Nの項を独立に広く包むと、符号付き相殺を再び失う。tに関する多項式を保持し、同じ係数を使う設計が必要である。

補助積分の費用が勝つ可能性がある。 特に接触近傍のa₀が小さいとw端点付近の変化が鋭くなる。wを解析的モーメントへ消す改良は有望だが、今回未実装である。

中心問題は自動解決しない。 (R4-20)は除算を除く厳密表示だが、導関数包囲が広い可能性は残る。

Wの符号自体が未確定である。 この報告には、全域W>0の証明も、W≤0の厳密な反例もない。§3.3の負値は積分核の局所的な負値である。

全域W>0が難しい場合には、ρ>0,z>0でEρ=0となる集合だけに制限する。その集合では

[
W=\lambda^2E_z/z.
]

従ってEρ=0上でW≠0を証明すれば、その集合に停留点はない。実装として、箱ごとにEρの区間が0を除けばそこで終了し、0を含む箱だけを条件付きW、陰関数の管、または二変数区間Newtonへ送る案がある。これは必要条件を弱めるが、全被覆・中心退化・境界接続の証明義務は残る。軸ρ=0には従来のZを使う。今回この条件付き非零性は証明していない。

Cp,Cm=C0+2*d*z*a*b,C0-2*d*z*a*b
Bp,Bm=B0-2*e*z*h*v,B0+2*e*z*h*v
def zreduce(expr):
    return s.rem(s.Poly(s.expand(expr),z),s.Poly(z*z-t*(1-t),z)).as_expr()
check('reflection_P_plus',zreduce(Cp*Bp-P0-2*z*D0))
check('reflection_P_minus',zreduce(Cm*Bm-P0+2*z*D0))
Delta=P0**2-4*t*(1-t)*D0**2
check('Delta_product',zreduce(Delta-Cp*Cm*Bp*Bm))
Cprod=1+2*d*((1-t)*b*b+t*a*a)+d*d*((1-t)*b*b-t*a*a)**2
check('C_positive_sum',zreduce(Cp*Cm-Cprod))
# Bbase=1-e+e*eta_y^2, eta_y^2=1-h^2-v^2.
Bbase=1-e*(h*h+v*v)
U=(1-t)*h*h+t*v*v
Bprod=Bbase**2+2*Bbase*e*U+e*e*((1-t)*h*h-t*v*v)**2
check('B_positive_sum',zreduce(Bp*Bm-Bprod))
Ppos=Bbase*C0+e*U+d*e*(t*(1-t)*(a*h-b*v)**2+((1-t)*b*h-t*a*v)**2)
check('P_positive_sum',Ppos-P0)
L=A+w*w*P
DD=P*P-z*z
SS=L*L-w**4*z*z
rp=a0/((P+z)*(A+w*w*(P+z)))
rm=a0/((P-z)*(A+w*w*(P-z)))
check('paired_first_derivative',(rp+rm)/2-a0*(P*L+w*w*z*z)/(DD*SS))
check('paired_J_derivative',(rp-rm)/(4*z)+a0*(L+w*w*P)/(2*DD*SS))
check('S_positive_sum',SS-(A*A+2*A*w*w*P+w**4*DD))
Pt,Jt=s.symbols('Pt Jt')
DT=2*P*Pt-Jt
N=(P*L+w*w*J)*Pt-(L+w*w*P)*Jt/2
check('common_numerator',N-(A*DT/2+w*w*(P*DT-(P*P-J)*Pt)))
R,q=s.symbols('R q')
k=1-R+R*q
S=(1-R)**2+2*R*q
check('zeta_lower_factor',k*k-q*S/2-(1-R)*((1-R)*(1-q/2)+R*q*(2-q)))
Dlinear=s.symbols('Dlinear0')+s.symbols('Dlinear1')*t
Jexpr=4*t*(1-t)*Dlinear**2
check('Jprime_at_zero',s.diff(Jexpr,t).subs(t,0)-4*Dlinear.subs(t,0)**2)
check('Jprime_at_one',s.diff(Jexpr,t).subs(t,1)+4*Dlinear.subs(t,1)**2)
check('sphere_P',P0.subs({d:0,e:0})-1)
check('sphere_t_derivative',s.diff(P0,t).subs({d:0,e:0}))
x=s.symbols('x',positive=True)
primitive=s.atan(s.sqrt(x))**2
check('atan_derivative',s.diff(primitive,x)-s.atan(s.sqrt(x))/((1+x)*s.sqrt(x)))
