## 2. Judge 裁定

**「採用：共回転＋赤道の凹性を主にする」**（ボタンによる選択。chat の推奨どおり）。

扁長 λ ∈ [2, 5] の大域定理の主な方針を、次のとおりとする。

| 条件 | 内容 |
|---|---|
| A | W ＝ λ²V − H > 0 |
| Z | 軸上で g ＞ 0 |
| C | 赤道上で Φ_s < 0 |
| Q | 中心の符号（窓全体） |
| B | 境界の符号（窓全体） |

これらを、§6 の条件付き定理で組み立てる。

- 停留円の枝を管で追跡すること（V25 の P2）は、必須の部品から外す。
- V25 の V の方針（相関を保った反射差商）は、予備として残す。
- Julia の系統の凍結は維持する。

**弱めた代わりの条件：** C が難しい場合は (21)、つまり「Φ ＝ 0 なら Φ_s < 0」に弱める。A が難しい場合は (22)、つまり「E_ρ ＝ 0 なら W ≠ 0」に弱める。どちらも難しい場合は、管の追跡または 2 変数の根の排除に戻る（Astra §9.4）。
