1. 結論と独立した問題診断
1.1 推奨する変更
最有力の研究案は、次の三条件を先に確立する構成である。
角度単調性：楕円体半径を固定して赤道から極へ動かすと E が増加する。
正の回転軸での単調性：E_z(0,z)>0、z>0。
赤道上の平方半径に関する厳密凹性：s=r²、Φ(s,λ)=F(r,λ)/r として Φ_s<0。
第1条件の対象は V 単独ではなく
[ \boxed{W=\lambda^2 V-H,\qquad V=E_z/z,\quad H=E_\rho/\rho.} \tag{1} ]
これは V>0 の言い換えではない。W>0 と軸上の排除で、非赤道停留点を排除する別の十分条件になる。必要なのは E_z=0 単独の排除ではなく、E_ρ=E_z=0 の同時成立の排除である。第3条件まで成立すれば、停留円の個数は中心と境界の符号だけで決まり、長い追跡管と管外の空白を別々に埋める工程を省ける。

2.1 支持関数表示を試した結果
法線 n で表し、楕円体の支持関数を h₀(n)、h_p=h₀−p·n とする。境界の半径ベクトルは
[ x-p=h_p n+\nabla_{S^2}h_p, \quad \alpha=\arctan\frac{|\nabla_{S^2}h_p|}{h_p}. ]
したがって E は h_p arctan²(|∇h_p|/h_p) の面積測度積分である。これは正確な別表示だが、f(t)=arctan²t は
[ f''(t)=\frac{2(1-2t\arctan t)}{(1+t^2)^2} ]
と符号を変える。単純な perspective 関数の凸性から E の凸性や鉛直単調性を引くことはできない。
錐体積測度については Böröczky–Lutwak–Yang–Zhang, The logarithmic Minkowski problem, §1, (1.1)–(1.2) [L1] を確認した。重み (x−p)·ν dA/3 との関係はあるが、同論文の測度実現問題を、基点に依存する角度二乗を掛けた本汎関数の停留点分類へ直接適用する根拠は得られていない。関連文献の存在と、本問題への適用可能性を区別する。今回の検索は網羅的な先行研究調査ではない。
3. 最有力案の導出：基点と積分座標を同時に回す
3.1 正規化と記号
正の相似不変性により
[ L=\operatorname{diag}(1,1,\lambda),\qquad K=L B^3 ]
で計算する。体積保存族はこれを λ^(−1/3) 倍したものなので、固定 λ における停留点の対応と符号は変わらない。旧扁長リポジトリの回転軸 y を、本稿では z と書く（y↔z）。
基点を
[ p=Lq,\quad q=R(\cos\beta,0,\sin\beta),\quad 0\le R\le1,\quad0\le\beta\le\pi/2 ]
とする。R は楕円体半径で、赤道の半径 r と区別する。赤道 β=0 では R=r。
ξ∈S²、x=Lξ とすると、面積と法線の共変換から
[ ((x-p)\cdot\nu),dA =\lambda(1-q\cdot\xi),d\Omega. ]
よって、k=1−q·ξ、D²=(ξ−q)^T L²(ξ−q)、B=ξ^T L^(−2)ξ として
[ \boxed{ E(p)=\frac1{4\pi}\int_{S^2} k, G!\left(\frac{k}{D\sqrt B}\right)d\Omega, \qquad G(c)=\arccos^2 c. } \tag{3} ]
これは正本の h=λk、w=λ√B を代入した式と一致する。積分の正規化を変更していない。
3.2 共回転と距離の因子分離
O_β を e_x を (cosβ,0,sinβ) に送る回転とし、ξ=O_βη と置く。球面測度は不変である。
[ v=\eta-Re_x,\quad \sigma=|v|,\quad m=O_\beta v/\sigma,\quad \xi=O_\beta\eta, \quad k=1-R\eta_x. ]
σ>0 の点で |m|=|ξ|=1。重要なのは、k と σ は β に依存しないことである。d=λ²−1、e=d/λ² とおくと
[ C=1+d m_z^2,\qquad B=1-e\xi_z^2,\qquad \gamma=\frac{k}{\sigma\sqrt{CB}}. \tag{4} ]
1≤C≤λ²、λ^(−2)≤B≤1。唯一の σ=0 は R=1, η=e_x であり、この一点を除いて計算する。
[ \mathcal R(c)=\frac{\arccos c}{\sqrt{1-c^2}},\qquad G'=-2\mathcal R ]
は c=1 で解析的に延長する。正本の級数・符号付き剰余 [S2] を再利用できる。
3.3 角度微分の厳密な核
回転に対して m_z'=m_x、m_x'=−m_z、ξ_z'=ξ_x、ξ_x'=−ξ_z である。そこで
[ T=\frac{d m_xm_z}{C}-\frac{e\xi_x\xi_z}{B}, \qquad \gamma_\beta=-\gamma T, \tag{5} ]
[ \begin{split} T_\beta={}&\frac{d(m_x^2-m_z^2)}C -2\left(\frac{d m_xm_z}C\right)^2\ &-\frac{e(\xi_x^2-\xi_z^2)}B -2\left(\frac{e\xi_x\xi_z}B\right)^2. \end{split} \tag{6} ]
f=kG(γ) とすれば
[ \boxed{f_\beta=2k\gamma\mathcal R T,} \tag{7} ]
[ \boxed{ f_{\beta\beta} =2k\gamma{\mathcal R T_\beta -(\mathcal R+\gamma\mathcal R')T^2}. } \tag{8} ]
証明。 (4)の対数微分が(5)。さらに微分して(6)。G'=-2ℛ と γ_β=-γT を用いれば(7)、(8)を得る。□
これらの式には m を作る際の σ は現れるが、m は単位ベクトルであり、(7)、(8)の値は接触距離の逆数として発散しない。生の区間式で m=v/σ を評価すると σ=0 の箱で失敗するので、これは「除算をそのまま実装してよい」という意味ではない。§4の球冠処理が必要である。
3.4 元の勾配との恒等式
[ \mathscr E(R,\beta;\lambda):=E(R\cos\beta,0,\lambda R\sin\beta). ]
内部では連鎖律により
[ \mathscr E_\beta =-R\sin\beta E_\rho+\lambda R\cos\beta E_z =R^2\sin\beta\cos\beta,W. \tag{9} ]
(7)を積分したものが左辺であることは、(3)の変数変換と微分から従う。別の検算として、球面の回転ベクトル場 X(ξ) に対して div_S X=0 なので
[ \int_{S^2}Xf,d\Omega=0 ]
を用いる。共回転時の微分は「基点の微分＋積分点の回転微分」であり、後者が積分後に消える。点ごとに二つの微分核が等しい、とは主張しない。
反射対称性から端点は
[ W(R,0)=\frac{\mathscr E_{\beta\beta}(R,0)}{R^2},\qquad W(R,\pi/2)=-\frac{\mathscr E_{\beta\beta}(R,\pi/2)}{R^2}. \tag{10} ]
R→0 では中心 Taylor 展開により
[ W(0;\lambda)=\lambda^2 Q_z(\lambda)-Q(\lambda), \quad Q=E_{xx}(0),\quad Q_z=E_{zz}(0). \tag{11} ]
中心係数の全 λ 窓での正値性は、新たに確認すべき一次元条件である。[S7] の Q_z の証拠を [2,5] 全体へ外挿しない。
3.5 角度関数のもう一つの有用な凹性
c₀=k/σ=m·ξ を固定し、P=CB とする。φ(P)=G(c₀/√P)、P≥c₀²、c₀>0 について
[ \phi'(P)=\frac{\gamma\mathcal R}P>0,\qquad \phi''(P)=-\frac{\gamma}{2P^2}(3\mathcal R+\gamma\mathcal R')<0. \tag{12} ]
実際、ℛ=∫₀∞(γ+cosh t)^(−1)dt より
[ \mathcal R+\gamma\mathcal R' =\int_0^\infty\frac{\cosh t}{(\gamma+\cosh t)^2}dt>0. ]
従って(12)の符号は厳密である。区間評価では φ の接線を上界、割線を下界に使え、平方根と逆三角関数を独立な区間として重ねる損失を減らす候補になる。ただし P 自体の β 依存は単調ではないので、(12)だけで W>0 は導けない。
4. 接触特異性の処理：全カラーに使える明示的補題
4.1 角度二階微分の一様支配
[ \ell=\lambda-\lambda^{-1},\quad C_\lambda=2(\lambda^2-1)+2\ell^2\le\frac{2352}{25}. ]
単位ベクトルの成分について、平方完成により
[ \frac{d|m_xm_z|}{1+d m_z^2}\le\frac d{2\lambda}, \qquad \frac{e|\xi_x\xi_z|}{1-e\xi_z^2}\le\frac d{2\lambda}. ]
例えば前者は (1+d t²)²−4λ²t²(1−t²)=(1−(λ²+1)t²)²≥0 から従う。後者は同じ二次形式の最小・最大固有値を交換した式である。
従って |T|≤ℓ。(6)の第1・第3項は各々絶対値≤d、二つの二乗項の合計は≤ℓ² なので
[ |T_\beta|\le2d+\ell^2. ]
また 0<ℛ+γℛ'≤ℛ≤π/2 より
[ \boxed{|f_{\beta\beta}|\le\pi C_\lambda k\gamma\le\pi C_\lambda k.} \tag{13} ]
同様に |f_β|≤πℓk。ここで k≤2 である。したがって R=1 でも支配収束により角度微分を積分内へ入れられる。接触一点では k=0 としてこれらの密度を0に延長できる。高階の角度微分も、C,Bの正の下界と角度関数の解析性により C_j k で支配される。ただし本稿で明示定数を与えるのは二階までである。
これは E のすべての空間方向の高階正則性を主張する補題ではない。楕円体半径を固定した角度方向に限定した改善である。
4.2 球冠の W 寄与
A_κ={η:1−η_x<κ}、0<κ≤2 とする。q_c=1−η_x と書けば、dΩ=2π dq_c、k=1−R+Rq_c。
[ \frac1{4\pi}\int_{A_\kappa}k,d\Omega =\frac12\left((1-R)\kappa+\frac{R\kappa^2}2\right). ]
A_κ は η_z の反射で不変である。この球冠だけを積分したエネルギーも β=0、π/2 で一階微分が0になる。平均値の定理と
[ \frac{\min(\beta,\pi/2-\beta)}{\sin\beta\cos\beta}\le\frac\pi2 ]
から、端点を含めて、その W への寄与 W_cap は
[ \boxed{ |W_{\rm cap}|\le \frac{\pi^2C_\lambda}{4R^2} \left((1-R)\kappa+\frac{R\kappa^2}2\right) \le \frac{1176}{5R^2} \left((1-R)\kappa+\frac{R\kappa^2}2\right). } \tag{14} ]
最後は π²<10 を使った厳密な有理上界である。R=0 へこの式を使わない。
具体例。 R∈[15/16,1]、κ=1/4096 なら
[ |W_{\rm cap}|\le \frac{301056}{1125} \left(\frac1{65536}+\frac1{33554432}\right) <\frac1{240}. \tag{15} ]
これは数値診断の余裕から選んだ定数ではなく、(14)からの有理計算である。W>0 を意味するものでもない。補集合の厳密積分下界がこの損失を上回る必要がある。
境界 R=1 での次数は κ² であり、距離逆数だけを面積で押さえる一般の Hessian 評価とは異なる。この改善の理由は、共回転によって特異な空間微分を避け、密度に k が残ることにある。
4.3 実装可能な一つのカラー方式
補集合では
[ \sigma^2=(1-R)^2+2R q_c\ge2R\kappa>0. ]
したがって R の箱が1を含んでも、(4)–(8)を通常の厳密区間演算で扱える。接触点を中心とする
[ u=\tan(\psi/4),\quad q_c=\frac{8u^2}{(1+u^2)^2},\quad \sin\psi=\frac{4u(1-u^2)}{(1+u^2)^2} ]
と θ の二変数積分を使えばよい。球冠の境界は代数的な u の端点として包囲できる。球冠誤差は一度だけ引く。
この方式は、外側面→極薄層→厚いカラーという別々の連続性定理を必須としない。一つの R 箱で閉境界まで扱う設計が可能である。ただし、実際の箱幅・求積誤差・計算量は未測定であり、同じ箱数で成功するとは主張しない。
4.4 赤道・極の商をどう評価するか
中間角では(7)を積分して R²sinβcosβ で割る。端点を含む箱では生の除算をしない。
β=0、π/2 の面には(8)、(10)を使う。
端点の近くでは η_z↔−η_z の反射対を先に合成し、β または π/2−β の因子を差商・偶数 Taylor 展開で除く。
やむを得ず角度二階微分の線分包絡を使う場合にも、(13)の有界核を使う。旧方式の E_zz の接触距離逆数を持ち込まない。
R=0 の近傍は(11)と中心 Taylor 剰余で処理する。β と R の二つの除算を同時に未処理の区間へ渡さない。
さらに s_β=sin²β、t=√(s_β(1−s_β)) とすれば、反射対の P=CB は P_±=P₀±2tD₀ と書ける。回転前の m₀=(η−Re_x)/σ に対して
[ C_0=1+d{(1-s_\beta)m_{0z}^2+s_\beta m_{0x}^2}, \quad B_0=1-e{(1-s_\beta)\eta_z^2+s_\beta\eta_x^2}, ] [ P_0=C_0B_0-4de,s_\beta(1-s_\beta)m_{0x}m_{0z}\eta_x\eta_z, \quad D_0=d m_{0x}m_{0z}B_0-e\eta_x\eta_z C_0. ]
反射対の密度は k{φ(P₊)+φ(P₋)}/2。この形は t の偶関数なので、平方根 t を独立な区間として残さず偶数差商にまとめる実装候補になる。符号の自明な正項表示ではない。
5. 赤道上を一つの凹性問題へ帰着する
e(s,λ)=E(√s,0,0)、s∈[0,1] と置く。中心の偶性から
[ \Phi(s,\lambda)=\frac{F(\sqrt s,\lambda)}{\sqrt s}=2e_s(s,\lambda), \quad \Phi(0,\lambda)=Q(\lambda). ]
したがって提案する条件は
[ \boxed{\Phi_s<0\quad\Longleftrightarrow\quad e_{ss}<0.} \tag{16} ]
これは E が位置 p の関数として凹であるという主張ではない。
5.1 exact 核と中心の接続
r>0 では
[ \boxed{\Phi_s=\frac{rE_{xx}(r,0,0)-E_x(r,0,0)}{2r^3}.} \tag{17} ]
正本の密度 ℱ=hG(γ) に対して、K_s=(rℱ_xx−ℱ_x)/(2r³) を共通の積分点で合成してから積分する。E_xx と E_x を別々の広い区間で積分して最後に引く方式は避ける。
中心では
[ E(r)=E(0)+\frac{Q}2r^2+\frac{H_4}{24}r^4+O(r^6), \quad \Phi_s(0,\lambda)=\frac{H_4(\lambda)}6. \tag{18} ]
内側の固定半径では、偶化した密度の四階微分剰余または中心級数を使える。参考となる厳密恒等式は
[ \Phi_s(r^2)=\frac14\int_0^1(1-t^2)E_{xxxx}(tr,0,0),dt \tag{19} ]
である。E'(0)=E'''(0)=0 と二度の積分から従う。ただし(19)を全境界に持ち込んで四階微分の正則性を仮定してはいけない。境界付近では二階までの(17)を使う。
5.2 残る数学的負担
本稿は(16)を解析的には証明していない。固定標本では負の符号が支持されたが、符号が変わる狭い領域や接触極限を排除していない。[S7] の H₄<0 は a_c 付近での入力であり、λ∈[2,5] の全域の H₄<0 ではない。
ただし、証明対象は外側変数 (s,λ) の二変数で、P3の三変数全域より小さい。局所分岐の係数、中心の帯、一般の赤道帯、境界の帯という既存部品を再利用しながら、管を追う代わりに単一の符号条件を検証する価値がある。
6. 全体を組み立てる条件付き構造定理

6.3 枝の接続も自動的に得られる
円上で F_r=2r²Φ_s<0 なので、内部では陰関数定理による局所的な枝が得られる。各 λ に一つしか零点がないため、これらは一つの枝につながる。
λ↓λ_b では r*→1、λ↑a_c では r*→0。例えば前者が成り立たなければ、部分列極限が内部の Φ=0 を与え、λ=λ_b での排除と矛盾する。後者も同様である。a_c 近傍では
[ r_*^2=-\frac{6Q(\lambda)}{H_4(a_c)}+o(a_c-\lambda) ]
が既存の局所展開と整合する。
この構成では「全枝を管で追うこと」が主定理の必須部品ではなくなる。既存の1スライスは回帰検査・正規化照合に使えるが、全枝の証拠へ格上げしない。
6.4 軸 Z の具体的な核
z=λt、0<t<1、μ∈[−1,1] とおき
[ A=1-t\mu,\quad D^2=1-\mu^2+\lambda^2(\mu-t)^2, \quad w^2=\lambda^2(1-\mu^2)+\mu^2, \quad\gamma=\frac{\lambda A}{wD}. ]
g(t,λ)=∂_t E(0,0,λt)=λE_z は
[ \boxed{ g=\frac12\int_{-1}^1 \left[-\mu G- \frac{2\lambda A\mathcal R(1-\mu^2) ((\lambda^2-1)\mu-\lambda^2t)}{wD^3}\right]d\mu. } \tag{20} ]
これは E=½∫A G dμ を微分するか、正本の E_z 核を軸に制限して得られる。t=0 の商は反射対で除去し、t≈1 の接触は μ=1−v² などの軸専用座標で扱う。Zには g>0 で十分で、g_t>0 は要求しない。今回の診断は後者の全域仮説を支持しなかった。
7. 失敗可能性と反例を調べた結果
7.1 共回転核は点ごとに正ではない
λ=2、R=1/2、cosβ=3/5、sinβ=4/5、η=−e_x とする。すると
[ C=73/25,\quad B=13/25,\quad k=3/2, \quad\gamma=25/\sqrt{949},\quad T=-189/949<0. ]
(7)により f_β<0 である。接触点ではなく、正則な積分点での厳密な反例である。η_z の反射でもこの点は動かない。η=+e_x を加えた対でも同じ T の符号になる。
従って「核の点ごとの正値」「単純な二点・四点反射平均の点ごとの正値」を根拠とする証明は成立しない。必要なのは、球面全体での重み付き相殺または積分不等式である。これは W>0 自体への反例ではない。
7.2 対称性だけでは非赤道停留点は消えない
例えば (ρ²−a)²+(z²−b)² は回転対称かつ赤道反射対称だが、a,b>0 で ρ²=a,z²=b の非赤道停留円を持つ。したがって「対称だから赤道に限られる」という一般論では足りない。楕円体と角度汎関数に固有のAまたは代替条件が必要である。
7.3 Φ_s<0 が失敗した場合
Φ_s が一点で非負になっても、停留円が増えるとは限らない。Cは便利な十分条件である。より弱い代替は
[ \Phi=0\ \Longrightarrow\ \Phi_s<0 \tag{21} ]
を全零点候補で示し、中心・境界の符号と合わせることである。内部のすべての零点が単純な下降交差なら、二つの下降交差の間には上昇交差または非単純零点が必要になるため、零点は高々一つ。端点近傍の零点集積は、端点の符号または局所分岐補題で別に排除する。実装上は零点を含み得る箱だけに(21)を要求できる。
7.4 W の符号が失敗した場合
W≤0 の領域があっても、そこに停留点があるとは限らない。ρ,z>0 では、E_ρ=0 上で W=λ²E_z/z なので
[ E_\rho=0\ \Longrightarrow\ W\ne0 \tag{22} ]
で足りる。E_ρ の符号が確定した箱を先に除き、残った箱で W または E_z を調べる。これでも残る連結成分にだけ二変数 interval Newton / Krawczyk 型の排除を使う。局所的な根の排除を全域排除と言い換えず、未被覆集合を台帳に残す必要がある。
7.5 その他の注意
中心での局所分岐は、遠方の別の停留円や非赤道分岐を排除しない。
数値的な正値標本は、狭い負領域や境界への零点集積を排除しない。
境界での W>0 は、内部の W>0 の代わりにならない。
λ=2 と5は閉端点として被覆する。a_c の有理包囲区間全体を「a_cそのもの」として一括分類しない。
a_c 以後の赤道の期待符号は F<0。H₄(a_c)<0 と Q'(a_c)<0 に整合する。
Morse 理論・次数の保存だけでは、相殺する余分な停留点対を排除できない。回転円の退化もあるため、指数の総和だけで個数を結論しない。
