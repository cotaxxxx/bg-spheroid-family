## 1. 中心の厳密一次元表示

回転楕円体の軸比を λ≥1 とする。角度 α の定義から、球面方向 u∈[0,1] について

```math
tan(alpha) = (lambda - 1/lambda) u sqrt(1-u^2).
```

この式は、元の cos(alpha)=λ/(wD) を用いて

```math
tan^2(alpha) = u^2 (1-u^2) (lambda^2-1)^2/lambda^2
```

と計算して得られる。角度二乗の球面平均は

```math
E_lambda(0) = integral_0^1 arctan^2((lambda-1/lambda)u sqrt(1-u^2)) du.
```

これは中心 p=0 に限った**厳密な表示**である。λ=1 で E_1(0)=0。極限 λ→∞ でほとんど至る所 α→π/2、かつ 0≤α²≤π²/4 なので

```math
lim_{lambda -> infinity} E_lambda(0) = pi^2/4.
```

Judge の報告では、上の一次元式と元の定義の数値積分が λ=2,5,100 で30桁一致した。

## 2. 対数補正と定数 +1

```math
t=lambda-1/lambda,   F(x)=pi^2/4-arctan^2(x),
Delta_lambda=pi^2/4-E_lambda(0).
```

積分定数の補題：

```math
lim_{T->infinity} [integral_0^T F(x) dx - pi log T] = pi(1-log 2).
```

Judge は T=10^9 における差が約 10^-9 であることを確認した。

赤道の境界層 u≈0 と外側領域を 1/t≪ε≪1 で分けると、形式的に

```math
Delta_lambda =
 (pi/t)[log(t epsilon)+1-log 2]
 +(pi/t)log(2/epsilon)
 +o(1/t)
 =(pi/t)(log t+1)+o(1/t).
```

したがって

```math
E_lambda(0)=pi^2/4-pi(log lambda+1)/lambda+o(1/lambda).
```

**意味**：対数係数だけでなく、補正の定数 `+1` も境界層と外側領域の相殺から現れる。

**厳密さの境界**：上の漸近導出は中心についての解析的な候補・導出スケッチである。論文用の完全な証明には、分割パラメータ ε の選択、内外近似の剰余が o(1/t) となる一様評価、積分・極限の交換条件を明記する。Judge は数値で t[Delta_lambda−π(log t+1)/t]→0 の挙動（λ=10 で約−0.49、λ=10^5 で約−0.00014）を確認したと報告している。**数値の収束傾向そのものを数学的剰余証明の代わりにはしない**。
