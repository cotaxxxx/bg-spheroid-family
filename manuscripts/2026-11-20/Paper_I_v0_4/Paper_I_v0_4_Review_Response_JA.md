# 論文 I v0.4　査読指摘への対応

扁長側の円の一意性は、赤道上の接方向四階微分と両端の符号から示す構成に改めた。形パラメータ方向の微分は、停留半径の移動方向を与える。186葉の旧計算は、この方法に至る最初の根探索実験として残した。

| 指摘 | 改訂稿での対応 | 検査の範囲 |
|---|---|---|
| C6 | 144ビット Arb と異なる角度分割で全1,024箱を再包囲。最小下界は 107156256170842/2^48 | 解析的に導いた同一の下側積分 |
| C5 | 6アンカーを160ビットArbで別計算。橋の弱い親79箱を各2分割 | 橋の再評価には元の弦核を使用 |
| C4 | 元の731個すべてを別実装で再包囲。新しい終端は1,043箱 | 赤道の四階微分。鉛直排除と形微分には既存の別の証拠を使う |
| C3の赤道 | [1,2]を加え、176葉と別実装399箱で同じ厳密な負符号を記録 | 正の境界トレースと合わせて中心以外を排除 |
| C1・C3の弱い葉 | 指定母集団277葉と28,358葉から各最弱1葉を選び、Arbで元の正下界を上回った | 全クラスからの無作為標本ではない。選択規則と符号未分離の粗い試行も収録 |
| 扁平中心 | 符号付き角から得た軸の積分で 0.407958860300 と 0.407958860301 の符号を分離 | 端点間の一意性は従来のC2を使用 |
| 自著 | 同じ汎関数を使った扁長局所論文・根区間原記録と三軸局所論文の公開説明を引用 | 20桁の根と局所分岐は先行成果。今回の対象は回転族の全域と境界 |
| 本文と補足 | 本文には監査範囲の表を置き、木の識別子、再試行、旧実行時間を独立した補足PDFへ移動 | 残る認証範囲と著者確認待ちを明記 |
| 三軸・縁 | 回転共変性から角方向の厳密な恒等式を導出。A/ρ²の4点と縁の8円弧×17点を2次数で計算 | 非区間。λ=0.42は扁平凹性予想の対象外 |

## 投稿判断

再査読用の研究稿。C1〜C6全体に対する入力・解析・算術・被覆の最終照合と採否、全証明資料を含むDOI付き固定公開、著者による本文とAI利用申告の確認が投稿前に残る。今回の再包囲は同じ研究作業内で作成した別実装であり、第三者による外部認証を意味しない。三軸の全域分類は未証明のままである。
