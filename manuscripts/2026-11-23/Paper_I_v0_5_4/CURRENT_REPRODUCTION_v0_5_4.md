## Which commands are actually reproducible in *this* bundled tree?

- `python verification/check.py`: **ledger/coverage and exact-rational checks** against archived output; does not redo the interval integrals. Requires Python 3 (plus standard library).
- `bash verification/reproduce.sh`: **bundled selected producer recalculation**. It runs endpoints, 1,024 C6 boxes, selected C4 radial/equatorial boxes, the bridge, and the near equator; it can require an Arb-capable Python environment, a rounding-aware compiler, and the correct historical dependencies. Successful execution **in this new release is not claimed**.
- `bash audit/reproduce.sh`: **radial archived-source calculation** plus selected checks; requires compilers and numerical dependencies. This is not a full C1–C6 replay.
- For complete original upstream claims, download and hash-verify the **fixed external archive** in the table before executing that archive's recorded commands. No new guessed command for a missing legacy C2 dependency is supplied.

## Limits and potential contradictions resolved

- Legacy `REPRODUCTION.md` predates the **current C6 second numerical integration** of 1,024 boxes and the **current `c_o` width-`10^{-12}` endpoints**. Current drivers and logged outputs are `verification/cap.py`, `verification/results/c6.csv`, `verification/endpoints.py`, `verification/results/endpoints.json`; the historical narrative is retained without overwriting.
- A producer's **domain cover** is not the same as a sample of boxes recomputed by a second evaluator: C1, C3 and C4 vertical/shape gates have bounded independent-check scopes as stated above.
- SHA-256 and Git object IDs check **identity**, not mathematical correctness. A fully independent analytic derivation of every C1–C6 kernel and a unified original-package replay remain **not demonstrated**.
