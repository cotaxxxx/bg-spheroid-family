## 求積の正しさの根拠

### 座標と完全密度

θ=πu、φ=πv、(u,v)∈[0,1]² とする。ξ=(sinθ cosφ,sinθ sinφ,cosθ)。
基点の y=0 なので y 反射で球面の残り半分を積分できる。
従って E、E_z、E_zz のそれぞれの球面密度 ℱ_* に対し

\[
E_* = \int_0^1\int_0^1 f_*(u,v)\,du\,dv,
\qquad f_* = \frac{\pi\sin(\pi u)}{2\lambda}\mathcal F_*.
\]

Jacobian と正規化因子を含む **完全密度** を微分する。
極で sqrt(1−μ²) を微分する方法は用いない。
R≤15/16、λ≥1 から D≥|ξ−L^{-1}p|≥1−R≥1/16。
全角度領域が正則で、今回は接触 cut は不要。

### 区間 Taylor／逐次中点 Peano 法

セル C=I_u×I_v、幅 h_u,h_v、中点 m のとき、任意の固定された
外部パラメータに対し、一次元中点則を順に適用すると

\[
\int_C f\in h_uh_v\left[
f(m)+\frac{h_u^2}{24}f_{uu}(C)
+\frac{h_v^2}{24}f_{vv}(m_u,I_v)\right].
\]

一次元の剰余は非負 Peano 核に f″ を掛けた積分で、その核の積分が h³/24。
従って上式は絶対誤差を隠した近似値ではなく、符号付き剰余を含む包囲。
二変数の混合微分を落とした Taylor 展開ではない。
`J` は value,f′,f″/2 の三係数を Arb で運ぶ。
u 方向は全セル、v 方向は中点線で評価する。コードでの係数は
h²/12×J.c[2]（J.c[2]=f″/2）になる。

さらに同じセルについて単純な範囲積分 `area(C)*f(C)` も包囲なので、
二つの包囲を交差する。各セルの包囲を外向き丸めで加算する。
求積点での値だけを積分値とみなす箇所はない。
分割は既定で 32×64=2,048 セル、完全密度評価は 6,144 回。
細分変更は API では可能だが、今回の較正は固定分割で行う。

### γ=1 と級数誤差

𝓡=Σ c_n(1−γ)^n、c₀=1、c_{n+1}=c_n(n+1)/(2n+3)。
N=96 で打ち切り、𝓡 の 0〜3 階微分と G の尾部を
厳密有理の片側区間で加える。一般項比から得る尾部の全式は
`LEMMAS_DRAFT.md` §6。G′=−2𝓡、G″=−2𝓡′。
ジェット合成によって必要な角度二階微分まで包囲する。
γ=1 で除算する処理はない。128/192 ビットは丸め精度であり、
求積誤差や固定 N の尾部を 128/192 ビットへ縮める指定ではない。

### 幾何学的交差と依存関係

0≤γ≤1、1≤w≤5、1−R_hi≤D≤5(1+R_hi)、|T|≤1 を
**真の写像像** に対する上界として使い、ジェットの定数係数だけを交差する。
微分係数を定数に置き換えない。Arb のボールに変換した後は半径が
外側へ膨らむことがあり、浮動小数の `min/max` で切らない。

ρ と z の外接直方体の全点が楕円体内にあるとは仮定しない。
外箱の実際の点 p(R,τ,λ)、または同じ点の縦線分上の点は
楕円体半径≤R_hi。固定したその点の全角度セルで幾何上界が成立するため、
区間式を真の点の部分集合に対して評価する論理が有効。

### V の二つの経路

- z の厳密有理下端が正：E_z の全箱包囲を z ボールで割る。
- z=0 に触れる：V=∫₀¹E_zz(ρ,sz)ds と、同じパラメータ箱の縦線分
  全体を包む E_zz 包囲を用いる。積分を追加の標本平均で置き換えない。

正の z 区間でも、下端が極端に小さいと Arb の半径丸めでゼロを
含むことがある。その場合は厳密有理端点から [1/z_hi,1/z_lo] を
作って乗じる。正の箱を赤道に触れる箱へ変更する処理ではない。

点の補助関数 `V_ball` は二つの有効な包囲を交差する。
赤道近傍の点の単純商だけでは、良い箱下界より低い「点の下端」を
返しうるためである。これは箱下界の誤りを意味しない。
箱の健全性検査では、この数学的に正当化された点包囲を比較する。

## 固定した較正と Dig の実行方法

依存は `requirements.txt`。核の必須依存は `python-flint==0.8.0` のみ、
`mpmath==1.3.0` は対照検査用。コードは Python 3.11 以降を対象とする。
実際に動かした Python・OS・flint は各実行記録に保存する。

環境の準備：`python -m pip install -r prolate_p3/requirements.txt`。
リポジトリルートで、研究用 PC の較正は次の **1 行**：

```bash
python -m prolate_p3.calibrate --out p3_calibration_20261116
```

27 箱×128/192 ビット。`boxes.json` は実行前に生成・固定済み。
R,τ の全幅は 1/64、λ の全幅は 1/256。端点アンカーでは、
範囲外を含めず全幅を保つため箱を内側に平行移動する。
例えば τ=0 は [0,1/64]、τ=1 は [63/64,1]、
λ=2 は [2,513/256]、λ=5 は [1279/256,5]。
内点アンカーは対称に半幅を置く。これを事前規則として一覧に記載した。

`PRE_RUN_SHA256.json` を検査し、箱・コード・分割の変更があれば停止。
結果による箱や分割の変更・自動再試行はしない。
同名の出力ディレクトリが既にある場合も停止し、上書きしない。
各箱・各精度を新しい子プロセスで測り、壁時計 ns と秒、
Linux の最大 RSS（KiB、Python 起動時メモリを含む）、
包囲の幅、セル数、下端・上端・下端符号を JSON と TSV に保存する。
壁時計は依存の import と固定ファイルの照合が終わった後から、
箱の評価・結果の有理端点化までを測る。プロセス起動時間は含めない。
下界そのものは半径ゼロなので、その幅 0 と V の包囲幅を別々に記録。
例外は失敗行と traceback に残し、出力を消さない。

Codex 側での較正試走は、固定一覧の **box 0 一つだけを両精度で** 実施する。
コマンドは `python -m prolate_p3.calibrate --one-box 0 --out prolate_p3/outputs/trial_one_box`。
