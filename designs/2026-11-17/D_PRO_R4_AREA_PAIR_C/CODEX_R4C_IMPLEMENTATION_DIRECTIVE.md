## 2. 厳密に実装する核

`R`・`tau`・`lambda`はfmpqの点または閉区間とする。内部で `t=4*tau^2/(1+tau^2)^2` を同じ変数の式として構成する。
`R>0`; `R=0`を含む箱は今回実装しない。球の対照 `lambda=1` は専用の検査入力として認める。
`eta=(h,eta_y,v)` を単位球点、`Sigma=(1-R)^2+2R(1-h)`、`k=1-R*h`、`a0=k^2/Sigma`、
`d=lambda^2-1`、`e=d/lambda^2`、`Bstar=lambda^(-2)+e*eta_y^2`、`U=(1-t)*h^2+t*v^2` と置く。
`a=(h-R)/sqrt(Sigma)`、`b=v/sqrt(Sigma)` は解析用記号であり、実装では平方根Sigmaを使わず次の有理平方式へ変形する。

```text
a² = (h-R)²/Sigma
b² = v²/Sigma
(a*h-b*v)² = (h*(h-R)-v²)²/Sigma
((1-t)*b*h - t*a*v)² = v²*((1-t)*h-t*(h-R))²/Sigma
C0 = 1 + d*((1-t)*b² + t*a²)
P = Bstar*C0 + e*U + d*e*( t*(1-t)*(a*h-b*v)² + ((1-t)*b*h-t*a*v)² )
DC = 1 + 2*d*((1-t)*b²+t*a²) + d²*((1-t)*b²-t*a²)²
DB = Bstar² + 2*Bstar*e*U + e²*((1-t)*h²-t*v²)²
Delta = DC*DB
A = a0*(1-w²)
S = A² + 2*A*w²*P + w⁴*Delta
N = (A/2)*Delta_t + w²*(P*Delta_t-Delta*P_t)
F = (2*k*a0/R²) * N/(Delta*S)
```

`P_t`, `Delta_t` は **tについての厳密な多項式微分**とする。`P²-J` の減算でDeltaを作らない。
`N` は正負項を無関係な区間にしてから合計せず、係数・共通変数の依存を保持した一つの多項式として構成する。
できれば t 方向Bernstein係数またはTaylorモデルを使用し、純自然区間式との共通部分を厳密に取る。ただし見込みによる幅縮小は認めない。
`F` は共回転球面の被積分核で、Wは `1/(4*pi)*integral_sphere integral_0^1 F dw dOmega`。

## 3. 分母正値と厳密な外包

- `lambda<=5`で `P>=lambda^(-2)`、`Delta>=lambda^(-4)>=1/625` を使用。
- `R<=Rstar<1`なら `a0>=(1-Rstar)^2/(1+Rstar)^2` を使用。境界R=1は球冠を除き `a0>=q_c/2>=kappa/2` を使用。
- `S >= min(a0_lower, lambda_max^(-2))^2`。正値を確認してから逆数jetを作る。
- Arbの自然計算区間が零をまたいでも、幾何的に証明した正の下界と交差させる。空交差や未有限係数は例外にする。
- 根拠のない epsilon の加算、都合のよいclip、浮動小数による剰余計算は禁止。
- 球面座標はR3の `u=tan(psi/4)`、`theta=pi*v_coord`、`h=1-8*u^2/(1+u^2)^2`、`v=4*u*(1-u^2)/(1+u^2)^2*cos(theta)`、`eta_y=...*sin(theta)` を採用。
- R3の正規化後Jacobian `8*u*(1-u^2)/(1+u^2)^3` を適用。反射平均で二重に2倍しない（定数関数の球面積テスト必須）。
- 球冠適用時は共回転R3と同じcap補正を外箱積分の最後に**一度だけ**加える。

## 4. 求積と外箱の要件

- 仮の実数積分を単なる浮動小数Gauss値で提出することは禁止。出力WはArbの証明付き外包でなければならない。
- `u,theta,w` 3方向の逐次区間Taylor求積を実装し、実際に評価した全セル高階微分で剰余を囲む。
- 対照式として、2次中点公式は `|I_C - |C|F(mid)| <= |C| sum_i(Delta_i^2 sup_C|partial_ii F|/24)`。6次を採用する場合は正しい6次の積分剰余を別に記載。
- 球面はR3既定の128-bit、6次、初期32×64、距離比1/4、lambda依存距離規則、最大深さ28、上限200,000セル。
- `w`方向は **64等分・6次区間Taylor求積・6階の全セル剰余**を最初の固定診断に採用する。結果を見て分割数を変えない。
- 外箱は `I(p0) + sum [partial_{R,tau,lambda}I](BOX)*(BOX-p0)`。導関数は共通したR,t,lambda依存を微分する。R微分のときa0,k,Sigmaも微分する。
- 外側補正はR、tau、lambda各項を別々に記録する。w剰余、球面剰余、球冠、分母下界、N範囲を独立表示する。
- 符号を細分判断に使わない。計算資源超過はTIMEOUT/OPENとし、中途結果をPASSにしない。
